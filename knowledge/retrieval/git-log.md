# git log 检索说明

## 用途与查询表达

查看提交历史及各提交的改动。适用实现：Git 2.23+。

- 查看提交记录。
- Git 历史图。
- 查看文件修改历史。

## 参数与行为

- `--oneline`：每条提交显示一行。
- `--graph`：显示分支图。
- `--all`：查看所有引用可达的提交。
- `-n N`：限制提交数量。
- `-p`：显示补丁。

## 常见任务示例

**1. 查看最近十条提交**

```bash
git log -n 10 --oneline
```

**2. 查看各分支的提交图**

```bash
git log --graph --oneline --all
```

**3. 查看指定文件的改动历史**

```bash
git log -p -- README.md
```

## 边界与易混淆点

默认从当前 HEAD 遍历；--all 包括本地已知引用，不会联网获取远程新历史。
