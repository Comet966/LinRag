# mpstat 检索说明

## 用途与查询表达

按 CPU 显示利用率与中断统计。适用实现：sysstat。

- 看每个核使用率。
- CPU 中断统计。
- 单核占用高。
- 和 top 区别。

## 参数与行为

- `-P ALL`：每个 CPU 各显示一行。
- `-P 0`：只看 0 号 CPU。
- `-u`：报告 CPU 利用率，默认开。
- `-A`：等价 `-u -P ALL`。
- `-I SUM`：报告中断统计汇总。
- `-o JSON`：以 JSON 格式输出。

## 常见任务示例

**1. 每 2 秒采样 3 次，按核分行**

```bash
mpstat -P ALL 2 3
```

**2. 只看中断统计**

```bash
mpstat -I SUM 1 2
```

**3. 输出 JSON 便于采集**

```bash
mpstat -o JSON 1 1
```

## 边界与易混淆点

不带间隔和次数时输出的是开机以来的平均值，看不出瞬时波动，要看实时得加 `间隔 次数`。
