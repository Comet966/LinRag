# tr 检索说明

## 用途与查询表达

按字符集转换、压缩或删除字符。适用实现：GNU coreutils。

- 大小写怎么转换。
- 批量删掉某些字符。
- 压缩连续重复字符。
- 去掉文件里的 ^M。

## 参数与行为

- `-d`：删除字符集1中的字符。
- `-s`：把连续重复字符压缩成一个。
- `-c`：改用字符集1的补集来处理。
- `-t`：先把字符集1截断到与2等长。
- `[:upper:]`：字符类，表示大写字母。

## 常见任务示例

**1. 大写转小写**

```bash
echo 'HELLO WORLD' | tr 'A-Z' 'a-z'
```

**2. 删掉所有数字**

```bash
echo 'a1b2c3' | tr -d '0-9'
```

**3. 压缩连续空格**

```bash
echo 'a    b' | tr -s ' '
```

## 边界与易混淆点

按字符而非字符串处理，整段替换要用 sed；删除需加 `-d`，否则必须给两个等长字符集。
