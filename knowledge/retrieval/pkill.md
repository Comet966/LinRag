# pkill 检索说明

## 用途与查询表达

按进程名或模式匹配并发送信号。适用实现：procps-ng。

- 按名字杀进程。
- 进程名太长匹配不到。
- 只杀最新的那个。
- 相比 killall。

## 参数与行为

- `-0`：只检查是否存在，不发信号。
- `-f`：匹配完整命令行而非进程名。
- `-x`：要求进程名完全一致。
- `-n`：只对最新的匹配进程操作。
- `-o`：只对最早的匹配进程操作。
- `-u`：只匹配指定用户的进程。
- `-e`：显示被处理的进程号。

## 常见任务示例

**1. 只检查是否在运行**

```bash
pkill -0 -x sshd
```

**2. 按完整命令行匹配**

```bash
pkill -0 -f 'python3 /opt/app/worker.py'
```

**3. 限定用户再匹配**

```bash
pkill -0 -u deploy -f 'python3 worker.py'
```

## 边界与易混淆点

默认按进程名匹配并发 SIGTERM；`-0` 只做探测不发信号，去掉即真正终止，先用 `pgrep -a` 确认。
