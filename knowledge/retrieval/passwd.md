# passwd 检索说明

## 用途与查询表达

修改用户密码并管理锁定状态。适用实现：shadow-utils。

- 怎么修改用户密码。
- 密码被锁怎么解锁。
- 查看密码过期状态。
- 普通用户改密码。

## 参数与行为

- `passwd`：修改当前用户自己的密码。
- `passwd USER`：root 修改指定用户密码。
- `-l`：锁定密码，禁止密码登录。
- `-u`：解除密码锁定。
- `-e`：让密码立即过期。
- `-S`：查看密码状态。

## 常见任务示例

**1. 修改自己的密码**

```bash
passwd
```

**2. root 设置指定用户密码**

```bash
sudo passwd alice
```

**3. 查看密码是否被锁定**

```bash
sudo passwd -S alice
```

## 边界与易混淆点

`-l` 只锁密码，SSH 密钥仍可登录；`-d` 清空密码等于允许无密码登录。
