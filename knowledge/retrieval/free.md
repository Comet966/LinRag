# free 检索说明

## 用途与查询表达

显示系统内存与交换空间使用情况。适用实现：procps-ng。

- 还有多少内存。
- 内存不足。
- 查看交换空间使用量。

## 参数与行为

- `-h`：以易读单位显示。
- `-m`：以 MiB 显示。
- `-g`：以 GiB 显示。
- `-s N`：每隔 N 秒刷新。
- `-t`：增加物理内存与交换空间合计行。

## 常见任务示例

**1. 查看内存和 swap 概况**

```bash
free -h
```

**2. 每隔两秒刷新内存概况**

```bash
free -h -s 2
```

## 边界与易混淆点

available 估算无需交换即可给新程序使用的内存；free 只表示完全空闲部分，缓存不等于内存泄漏。
