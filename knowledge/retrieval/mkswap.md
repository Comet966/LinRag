# mkswap 检索说明

## 用途与查询表达

在设备或文件上建交换区，会覆盖内容。适用实现：util-linux。

- 怎么建交换分区。
- 建 swap 文件。
- swap 建了没生效。
- swapon 怎么用。

## 参数与行为

- `-c`：建立前检查坏块，较慢。
- `-f`：跳过尺寸检查强制建立。
- `-L LABEL`：设置交换区卷标。
- `-U UUID`：指定交换区 UUID。
- `-p SIZE`：指定页大小（字节）。

## 常见任务示例

**1. 在占位分区建交换区（有风险）**

```bash
mkswap /dev/sdXN
```

**2. 为交换文件设置卷标**

```bash
mkswap -L swap1 /swapfile1
```

**3. 建立前先检查坏块**

```bash
mkswap -c /dev/sdXN
```

## 边界与易混淆点

会覆盖目标设备或文件原有数据，执行前务必确认设备名；建好后还要 `swapon` 才生效。
