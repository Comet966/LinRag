# top 检索说明

## 用途与查询表达

交互查看进程和 CPU、内存等资源使用情况。适用实现：procps-ng。

- 哪个进程占 CPU。
- 实时看内存。
- 服务器负载高。
- 进程资源排行。

## 参数与行为

- `-d N`：设置刷新间隔秒数。
- `-p PID`：只监控指定进程。
- `-b`：批处理模式，适合输出到文件。
- `-n N`：刷新指定次数后退出。

## 常见任务示例

**1. 输出一次系统和进程快照**

```bash
top -b -n 1
```

**2. 持续监控指定进程，每两秒刷新**

```bash
top -p 1234 -d 2
```

## 边界与易混淆点

交互界面按 q 退出，P 按 CPU 排序，M 按内存排序。负载平均值与 CPU 使用率含义不同。
