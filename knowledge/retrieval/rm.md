# rm 检索说明

## 用途与查询表达

删除文件；指定递归选项后可删除目录。适用实现：GNU coreutils。

- 删除文件。
- 清理不需要的文件。
- 移除非空目录。

## 参数与行为

- `-i`：每次删除前询问。
- `-I`：删除超过三个文件或递归删除时询问一次。
- `-r`：递归删除目录及内容。
- `-f`：忽略不存在的文件且不提示。
- `-v`：显示删除的路径。

## 常见任务示例

**1. 确认后删除一个文件**

```bash
rm -i old.txt
```

**2. 删除多个文件，每个文件都先确认**

```bash
rm -i old-a.txt old-b.txt
```

## 边界与易混淆点

不移入桌面回收站。删除选项有风险，示例使用交互确认；空目录也可用 rmdir。
