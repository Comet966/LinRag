# chgrp 检索说明

## 用途与查询表达

修改文件或目录的所属用户组。适用实现：GNU coreutils。

- 改文件所属组。
- 递归改目录属组。
- 只看改动过的文件。
- 按参考文件改组。

## 参数与行为

- `-R`：递归处理子目录与文件。
- `-v`：逐个显示处理结果。
- `-c`：只在确有更改时输出。
- `-f`：不显示错误信息。
- `-h`：只改符号链接本身。
- `--reference=RFILE`：组改为参考文件的组。

## 常见任务示例

**1. 改单个文件的所属组**

```bash
chgrp www-data index.html
```

**2. 递归改整棵目录树**

```bash
chgrp -R www-data /var/www
```

**3. 参照另一个文件同步组**

```bash
chgrp --reference=ref.txt a.txt
```

## 边界与易混淆点

只有 root 或目标组成员能改组；`-h` 改的是链接自身，不加则跟随到目标文件。
