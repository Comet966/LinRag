# git reset 检索说明

## 用途与查询表达

调整暂存区，或将当前分支移动到指定提交。适用实现：Git 2.23+。

- 撤销最近提交保留代码。
- 取消暂存。
- soft mixed hard 区别。

## 参数与行为

- `--soft`：只移动 HEAD，保留暂存区和工作区。
- `--mixed`：移动 HEAD 并重置暂存区，保留工作区。
- `--hard`：同时重置 HEAD、暂存区和工作区。

## 常见任务示例

**1. 取消单个文件暂存**

```bash
git reset HEAD -- README.md
```

**2. 撤回最近一次本地提交但保留暂存内容**

```bash
git reset --soft HEAD~1
```

**3. 撤回本地提交并保留工作区修改**

```bash
git reset --mixed HEAD~1
```

## 边界与易混淆点

后两个例子假设存在父提交且提交尚未共享；--hard 会丢弃已跟踪文件修改，并可能删除阻挡写入的未跟踪内容。
