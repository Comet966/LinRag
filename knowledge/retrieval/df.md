# df 检索说明

## 用途与查询表达

显示文件系统的容量和可用空间。适用实现：GNU coreutils。

- 磁盘还剩多少空间。
- 分区满了。
- inode 用完。
- 查看挂载盘容量。

## 参数与行为

- `-h`：以 1024 为基数显示易读单位。
- `-H`：以 1000 为基数显示易读单位。
- `-T`：显示文件系统类型。
- `-i`：显示 inode 使用情况。

## 常见任务示例

**1. 查看当前目录所在文件系统的剩余空间**

```bash
df -h .
```

**2. 查看 inode 是否耗尽**

```bash
df -i .
```

## 边界与易混淆点

df 汇总文件系统，du 统计目录文件占用；文件删除后仍被进程打开可能继续占空间。
