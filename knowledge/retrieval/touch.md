# touch 检索说明

## 用途与查询表达

创建空文件，或更新已有文件的时间戳。适用实现：GNU coreutils。

- 新建空文件。
- 更新文件修改时间。
- 复制时间戳。

## 参数与行为

- `-a`：只更新访问时间。
- `-m`：只更新修改时间。
- `-c`：文件不存在时不创建。
- `-r FILE`：使用参考文件的时间。
- `-t STAMP`：指定时间，格式 [[CC]YY]MMDDhhmm[.ss]。

## 常见任务示例

**1. 创建文件或更新它的时间**

```bash
touch notes.txt
```

**2. 仅更新已有文件的修改时间，不创建缺失文件**

```bash
touch -cm notes.txt
```

## 边界与易混淆点

已有文件的内容不会被清空；touch 不负责写入正文。
