# ls 检索说明

## 用途与查询表达

列出目录中的文件和子目录。适用实现：GNU coreutils。

- 找隐藏文件。
- 查看目录内容。
- 按时间列文件。
- 列出文件权限。

## 参数与行为

- `-a`：包括以点开头的隐藏项。
- `-A`：包括隐藏项，但排除 . 和 ..。
- `-l`：以长格式显示权限、属主、大小和时间。
- `-1`：每行只显示一个名称。
- `-h`：配合 -l，以易读单位显示大小。
- `-R`：递归列出子目录。
- `-t`：按修改时间排序，较新的在前。
- `-S`：按大小排序，较大的在前。
- `-r`：反转排序。
- `-d`：显示目录本身，不展开内容。

## 常见任务示例

**1. 查看当前目录的隐藏文件、大小和权限**

```bash
ls -lah .
```

**2. 按修改时间查看最近变动的文件**

```bash
ls -lt .
```

## 边界与易混淆点

只列目录条目，不读取文件正文；搜索正文用 grep。-l 是长格式，-1 才是每行一个名称。
