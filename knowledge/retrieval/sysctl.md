# sysctl 检索说明

## 用途与查询表达

查看与临时修改内核运行参数。适用实现：procps-ng。

- 查看内核参数。
- 调 TCP 参数。
- 改了为何不生效。
- 永久生效怎么写。

## 参数与行为

- `-a`：显示全部可读的内核参数
- `-n`：只打印值，不打印键名
- `-N`：只打印参数名称
- `-e`：忽略未知键名的错误
- `-p`：从配置文件加载参数设置
- `-w`：写入参数值，会修改内核

## 常见任务示例

**1. 查看全部内核参数**

```bash
sysctl -a
```

**2. 只读取一个参数的值**

```bash
sysctl -n vm.swappiness
```

**3. 按前缀筛出 TCP 参数**

```bash
sysctl -a | grep net.ipv4.tcp
```

## 边界与易混淆点

`-w` 以及不带 `-w` 的直接赋值都会改内核且重启失效；要永久生效写 `/etc/sysctl.d/`。
