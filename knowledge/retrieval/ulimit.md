# ulimit 检索说明

## 用途与查询表达

限制当前 shell 会话可用资源。适用实现：Bash 内建。

- 打开文件数受限。
- 怎么调大句柄数。
- 查看资源限制。
- 改了为什么没生效。

## 参数与行为

- `-a`：显示全部资源限制。
- `-n`：打开文件描述符数上限。
- `-c`：core 文件大小上限。
- `-s`：栈大小上限，单位 KB。
- `-H`：设置硬限制。
- `-u`：单用户进程数上限。

## 常见任务示例

**1. 查看全部限制**

```bash
ulimit -a
```

**2. 只查句柄上限**

```bash
ulimit -n
```

**3. 本会话临时调高**

```bash
ulimit -n 4096
```

## 边界与易混淆点

是 shell 内建，只影响当前 shell 及其子进程；调低硬限制后无法再调高，需 root 才能提高。
