# chmod 检索说明

## 用途与查询表达

修改文件或目录的访问权限。适用实现：GNU coreutils。

- 脚本没有执行权限。
- 设置 rwx。
- 修改文件权限。
- chmod 755。

## 参数与行为

- `-R`：递归修改目录及内容。
- `-v`：显示处理信息。
- `-c`：只报告实际改变的权限。
- `--reference=FILE`：使用参考文件的权限。

## 常见任务示例

**1. 给文件所有者增加执行权限**

```bash
chmod u+x script.sh
```

**2. 将文件权限设为仅属主可读写**

```bash
chmod 600 secrets.conf
```

**3. 为属主增加目录访问权限**

```bash
chmod u+x private/
```

## 边界与易混淆点

u 表示文件所有者，g 为所属组，o 为其他人；不是“当前登录用户”。目录的 x 控制进入和路径查找。
