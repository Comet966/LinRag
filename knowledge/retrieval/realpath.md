# realpath 检索说明

## 用途与查询表达

把相对路径和符号链接解析成绝对路径。适用实现：GNU coreutils。

- 取文件绝对路径。
- 解析软链接真身。
- 规范化路径写法。
- 脚本里求真实路径。

## 参数与行为

- `-e`：要求所有路径组件都存在。
- `-m`：组件不存在也正常规范化。
- `-L`：按逻辑解析符号链接，默认。
- `-P`：按物理路径解析符号链接。
- `-s`：去掉结果末尾多余的斜杠。
- `-z`：输出以 NUL 分隔，便于脚本。
- `--relative-to=DIR`：输出相对目录的路径。

## 常见任务示例

**1. 取文件的真实绝对路径**

```bash
realpath ./conf/app.ini
```

**2. 解析符号链接指向的目标**

```bash
realpath /usr/bin/env
```

**3. 路径不存在也规范化输出**

```bash
realpath -m ./no/such/dir
```

## 边界与易混淆点

`-m` 不检查存在性，`-e` 要求全部存在否则报错；默认保留末尾斜杠，需 `-s` 去掉。
