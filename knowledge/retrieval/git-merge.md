# git merge 检索说明

## 用途与查询表达

把其他分支的历史合并到当前分支。适用实现：Git 2.23+。

- 合并分支。
- 处理合并冲突。
- 仅允许快进合并。

## 参数与行为

- `--ff-only`：仅允许快进合并。
- `--no-ff`：禁用快进并建立合并提交。
- `--abort`：尝试中止正在进行的合并。

## 常见任务示例

**1. 仅在能够快进时合并更新**

```bash
git merge --ff-only origin/main
```

**2. 将功能分支合并到当前分支**

```bash
git merge feature/demo
```

**3. 冲突后中止当前合并**

```bash
git merge --abort
```

## 边界与易混淆点

在当前分支操作；冲突需人工处理，合并前保留或提交本地工作，--abort 不保证恢复合并前未提交的修改。
