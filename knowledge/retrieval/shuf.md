# shuf 检索说明

## 用途与查询表达

随机打乱或抽取输入行。适用实现：GNU coreutils。

- 随机抽几行。
- 打乱文件行。
- 随机抽样。
- 生成随机序号。

## 参数与行为

- `-n N`：只输出前 N 行。
- `-i LO-HI`：按数字范围生成输入。
- `-e`：把每个参数当作一行。
- `-r`：抽取结果允许重复。
- `-o FILE`：把结果写入文件。
- `--random-source=FILE`：指定随机源。

## 常见任务示例

**1. 从 1 到 100 中抽 5 个**

```bash
shuf -i 1-100 -n 5
```

**2. 打乱名单文件并查看结果**

```bash
shuf /tmp/names.txt
```

## 边界与易混淆点

默认不放回抽样，-r 才允许重复；-i 的区间包含两端，不改变原文件。
