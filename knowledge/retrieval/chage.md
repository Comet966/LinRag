# chage 检索说明

## 用途与查询表达

查看和修改密码有效期与账号过期。适用实现：shadow-utils。

- 查看密码何时过期。
- 设置密码最长天数。
- 账号到期怎么停用。
- 密码过期前提醒。

## 参数与行为

- `-l`：列出当前的过期策略。
- `-M 90`：密码最长有效天数。
- `-m 7`：两次改密的最小间隔天数。
- `-W 14`：密码过期前的警告天数。
- `-I 5`：密码过期后的宽限天数。
- `-E 2025-12-31`：账号到期日，过期即停用。
- `-d 0`：把最后改密日期设为今天。

## 常见任务示例

**1. 查看账号的过期策略**

```bash
chage -l alice
```

**2. 密码 90 天过期并提前 14 天警告**

```bash
chage -M 90 -W 14 alice
```

**3. 设置账号到期日**

```bash
chage -E 2025-12-31 alice
```

## 边界与易混淆点

改的是 `/etc/shadow` 里的字段，`-l` 只读；`-d 0` 会强制用户下次登录改密。
