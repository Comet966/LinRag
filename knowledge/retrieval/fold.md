# fold 检索说明

## 用途与查询表达

按指定宽度把每行折成多行。适用实现：GNU coreutils。

- 内容超宽怎么折。
- 按列宽截断显示。
- 在空格处换行。
- 和 fmt 有何区别。

## 参数与行为

- `-w 40`：指定每行最大列宽。
- `-s`：尽量在空格处折行。
- `-b`：按字节而非列数计宽。
- `--help`：显示帮助并退出。
- `--version`：显示版本并退出。

## 常见任务示例

**1. 每行最多 40 列折行**

```bash
fold -w 40 note.txt
```

**2. 在空格处折行更整齐**

```bash
fold -s -w 40 note.txt
```

**3. 按字节宽度折行**

```bash
fold -b -w 20 data.bin
```

## 边界与易混淆点

只按宽度硬折行，不做分词，默认 80 列；要和 `fmt` 的段落重排区分开。
