# su 检索说明

## 用途与查询表达

切换到其他用户身份。适用实现：util-linux。

- 怎么切换到 root。
- 切换用户跑命令。
- 登录式切换区别。
- 切换后环境不对。

## 参数与行为

- `su -`：登录式切换，加载完整环境。
- `su`：非登录式，保留当前环境。
- `-c 'CMD'`：以目标用户执行一条命令。
- `-s SHELL`：指定使用的 shell。
- `-m`：保留当前环境变量。
- `-g GROUP`：指定主组，仅 root 可用。

## 常见任务示例

**1. 切换到 root 登录环境**

```bash
su -
```

**2. 以 alice 执行命令**

```bash
su - alice -c 'id'
```

**3. 保留当前环境切换**

```bash
su -m alice
```

## 边界与易混淆点

`su -` 重置 HOME 和 PATH，`su` 保留原环境；普通用户需目标用户密码。
