# renice 检索说明

## 用途与查询表达

调整运行中进程的 nice 调度优先级。适用实现：util-linux。

- 改进程优先级。
- 降低进程占用。
- 调整 nice 值。
- 让进程更让出 CPU。

## 参数与行为

- `-n 值`：设置 nice，范围 -20 到 19。
- `-p PID`：按进程号调整，默认方式。
- `-g PGID`：按进程组调整优先级。
- `-u 用户`：调整该用户全部进程。
- `--help`：显示帮助后退出。
- `--version`：显示版本信息。

## 常见任务示例

**1. 把进程 1234 调低优先级**

```bash
renice -n 10 -p 1234
```

**2. 统一调整某用户的进程**

```bash
renice -n 5 -u www-data
```

**3. 确认调整后的 nice 值**

```bash
ps -o pid,ni,cmd -p 1234
```

## 边界与易混淆点

值越大越不优先；负数或改他人进程需 root，`-n` 须放首位。`nice` 只在启动时设定。
