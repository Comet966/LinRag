# host 检索说明

## 用途与查询表达

查询域名与 IP 的 DNS 记录。适用实现：BIND utils。

- 查域名解析结果。
- 查 MX 邮件记录。
- 反查 IP 的域名。
- dns 查询不生效。

## 参数与行为

- `-t A`：只查指定类型的记录。
- `-a`：显示全部 DNS 信息。
- `-v`：显示查询的详细过程。
- `-4`/`-6`：只用 IPv4 或 IPv6。
- `-W 2`：设置等待应答的秒数。
- `-r`：关闭递归查询。

## 常见任务示例

**1. 查域名对应的 IP**

```bash
host example.com
```

**2. 只查 MX 邮件记录**

```bash
host -t MX example.com
```

**3. 反查 IP 对应的域名**

```bash
host 8.8.8.8
```

## 边界与易混淆点

只做一次查询，不做逐跳追踪；看完整解析链用 `dig +trace`，看链路用 `mtr`。
