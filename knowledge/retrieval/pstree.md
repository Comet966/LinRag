# pstree 检索说明

## 用途与查询表达

以树状图显示进程间的父子派生关系。适用实现：psmisc。

- 查看进程树结构。
- 进程父子关系。
- 找出服务的主进程。
- 按 PID 看进程树。

## 参数与行为

- `-p`：显示每个进程的 PID。
- `-a`：显示完整的命令行参数。
- `-u`：显示进程所属用户名。
- `-n`：按 PID 排序，不按名称。
- `-h`：高亮当前进程及其祖先。
- `-A`：用 ASCII 字符画树防乱码。

## 常见任务示例

**1. 查看进程树与 PID**

```bash
pstree -p
```

**2. 显示完整命令行参数**

```bash
pstree -a
```

**3. 高亮自己所在的分支**

```bash
pstree -h
```

## 边界与易混淆点

默认把线程压缩成 `{}` 显示，`-T` 可隐藏线程；只画父子关系，占用看 `top`。
