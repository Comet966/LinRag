# sha256sum 检索说明

## 用途与查询表达

计算或核对文件的 SHA-256 摘要。适用实现：GNU coreutils。

- 验证下载镜像。
- 生成校验值。
- 校验失败原因。
- 摘要算法怎么选。

## 参数与行为

- `-c`：按清单核对摘要。
- `--quiet`：只输出校验失败项。
- `--status`：不输出，只用退出码。
- `-b`：以二进制模式读取。
- `--tag`：输出 BSD 风格摘要。

## 常见任务示例

**1. 生成 SHA-256 清单**

```bash
sha256sum ubuntu.iso > ubuntu.iso.sha256
```

**2. 按清单核对镜像**

```bash
sha256sum -c ubuntu.iso.sha256
```

**3. 只取摘要值**

```bash
sha256sum ubuntu.iso | cut -d ' ' -f 1
```

## 边界与易混淆点

摘要一致只说明内容与清单相符，不能代替签名验证；清单路径相对当前目录。
