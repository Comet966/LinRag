# unrar 检索说明

## 用途与查询表达

从 rar 包中列出或解压文件。适用实现：unrar。

- 怎么解压 rar。
- 查看 rar 内容。
- 解压后路径乱了。
- 覆盖同名文件。

## 参数与行为

- `x`：保留包内相对路径解压。
- `e`：解压到当前目录，不保留路径。
- `l`：列出压缩包内文件。
- `t`：测试压缩包是否完好。
- `-o+`：同名文件直接覆盖。
- `-y`：所有询问都回答是。

## 常见任务示例

**1. 查看包内文件**

```bash
unrar l /tmp/demo.rar
```

**2. 解压到指定目录**

```bash
unrar x /tmp/demo.rar /tmp/demo-out/
```

**3. 先测试能否解压**

```bash
unrar t /tmp/demo.rar
```

## 边界与易混淆点

`x` 保留包内相对路径，`e` 把文件全平铺到当前目录；命令名不加横线，开关才加 `-`。
