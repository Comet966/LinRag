# locate 检索说明

## 用途与查询表达

从索引数据库快速查找文件路径。适用实现：plocate / mlocate。

- 文件名在哪。
- 快速找文件。
- 按名字搜路径。
- find 太慢了。

## 参数与行为

- `-i`：匹配时忽略大小写。
- `-c`：只输出匹配数量。
- `-l N`：限制输出的条目数。
- `-b`：只匹配路径最后一段。
- `-e`：只输出仍然存在的结果。
- `-S`：打印数据库的统计信息。

## 常见任务示例

**1. 查找名称含 sshd 的路径**

```bash
locate sshd
```

**2. 忽略大小写并限制条数**

```bash
locate -i -l 5 nginx
```

**3. 只统计仍存在的匹配数**

```bash
locate -e -c nginx
```

## 边界与易混淆点

`locate` 只查索引库，新文件要先跑 `updatedb` 才可见；精确查找仍用 `find`。
