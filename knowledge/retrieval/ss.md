# ss 检索说明

## 用途与查询表达

查看套接字连接和监听端口。适用实现：iproute2。

- 哪个进程监听端口。
- TCP 连接。
- 端口占用。
- 替代 netstat。

## 参数与行为

- `-l`：只显示监听套接字。
- `-a`：显示监听和非监听套接字。
- `-n`：使用数字地址和端口，不解析名称。
- `-t`：筛选 TCP。
- `-u`：筛选 UDP。
- `-p`：显示关联进程。
- `-s`：显示摘要。

## 常见任务示例

**1. 查看 TCP 监听端口及关联进程**

```bash
ss -lntp
```

**2. 查看当前 TCP 连接，使用数字地址和端口**

```bash
ss -tn
```

**3. 查看 UDP 监听套接字及关联进程**

```bash
ss -lunp
```

## 边界与易混淆点

查看其他用户进程可能需要权限；-l 限定监听，-a 包含各类状态。这里只描述本机套接字，不做远程端口扫描。
