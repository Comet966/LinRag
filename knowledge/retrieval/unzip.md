# unzip 检索说明

## 用途与查询表达

查看或解压 ZIP 压缩包。适用实现：Info-ZIP UnZip。

- 解压 zip。
- 查看 zip 内容。
- 校验压缩包。
- 指定解压路径。

## 参数与行为

- `-l`：列出压缩包中的文件。
- `-t`：测试归档完整性。
- `-d DIR`：指定解压目录。
- `-n`：不覆盖已存在的文件。
- `-o`：覆盖已有文件且不询问。
- `-q`：减少输出。

## 常见任务示例

**1. 解压到指定目录，保留已有文件**

```bash
unzip -n project.zip -d extracted/
```

**2. 只列出 ZIP 中的文件，不解压**

```bash
unzip -l project.zip
```

## 边界与易混淆点

-n 和 -o 的覆盖策略不同，不要一起使用；unzip 处理 ZIP，不用于 tar.gz。
