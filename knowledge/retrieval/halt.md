# halt 检索说明

## 用途与查询表达

停止系统，现代 systemd 下等同关机。适用实现：systemd。

- 怎么安全关机。
- halt 会直接断电吗。
- 停机和关机区别。
- 必须先 sync 吗。

## 参数与行为

- `--help`：显示帮助并退出。
- `-p`：关机并切断电源。
- `-f`：不停服务，强制停机。
- `-w`：只写 wtmp，不真停机。
- `-d`：不写 wtmp 记录。
- `--no-wall`：不发送警告消息。

## 常见任务示例

**1. 只看用法，绝不执行**

```bash
halt --help
```

**2. 查手册确认影响范围**

```bash
man halt
```

## 边界与易混淆点

现代 systemd 下 `halt` 等同关机；示例只留 `--help` 等只读形式，勿在生产执行。
