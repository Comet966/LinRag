# nethogs 检索说明

## 用途与查询表达

按进程实时统计网络带宽。适用实现：nethogs。

- 哪个进程在占带宽。
- 看网卡的实时流量。
- 下载慢是谁在跑。
- 按进程看上传量。

## 参数与行为

- `-d 秒`：设刷新间隔，默认 1 秒。
- `-v 模式`：切换单位，0 为 KB/s。
- `-c 次数`：刷新够次数后自动退出。
- `-t`：跟踪模式，输出不刷屏。
- `-s`：按发送流量排序。
- `-a`：连环回等接口一起监控。

## 常见任务示例

**1. 每 2 秒刷新一次总览**

```bash
sudo nethogs -d 2
```

**2. 只看 eth0 的进程流量**

```bash
sudo nethogs -d 1 eth0
```

**3. 记 10 次后自动退出**

```bash
sudo nethogs -t -c 10
```

## 边界与易混淆点

需 root 权限按 PID 归集流量；只显示实时速率不留历史，与 iftop 按连接统计不同。
