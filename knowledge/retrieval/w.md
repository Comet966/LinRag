# w 检索说明

## 用途与查询表达

显示登录用户与其当前命令。适用实现：procps-ng。

- 谁在线在干什么。
- 看登录用户的来源。
- 负载多高算正常。
- 和 who 有何区别。

## 参数与行为

- `-h`：不打印表头。
- `-s`：使用精简输出格式。
- `-u`：算当前进程时间时忽略用户名。
- `-i`：来源地址显示为 IP。
- `-o`：老式固定列宽输出。

## 常见任务示例

**1. 谁在线在干什么**

```bash
w
```

**2. 精简格式看用户**

```bash
w -s
```

**3. 只看某个用户**

```bash
w root
```

## 边界与易混淆点

首行给出时间和负载均值；`w` 还带当前命令与 CPU 占用，`who` 只列会话。
