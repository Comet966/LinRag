# split 检索说明

## 用途与查询表达

按大小或行数切分文件。适用实现：GNU coreutils。

- 大文件切块。
- 按行切分。
- 按大小分割。
- 切分后合并。

## 参数与行为

- `-b SIZE`：按字节大小切分。
- `-l N`：按行数切分。
- `-n N`：切成 N 个大致等大的块。
- `-d`：后缀用数字而非字母。
- `-a N`：设置后缀长度。
- `--verbose`：每生成一块打印信息。

## 常见任务示例

**1. 每 10MB 切一块，数字后缀**

```bash
split -b 10M -d /tmp/big.log /tmp/part_
```

**2. 每 1000 行切一块**

```bash
split -l 1000 /tmp/big.log /tmp/chunk_
```

## 边界与易混淆点

不删除原文件；默认后缀为字母，-d 改数字，-a 控位数；合并按序 cat。
