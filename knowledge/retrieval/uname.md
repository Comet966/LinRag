# uname 检索说明

## 用途与查询表达

显示内核和系统信息。适用实现：GNU coreutils。

- Linux 内核版本。
- 系统架构。
- 机器是否 x86_64。
- 系统内核名称。

## 参数与行为

- `-a`：显示多项系统信息。
- `-s`：显示内核名称。
- `-r`：显示内核发行版本。
- `-m`：显示机器硬件名称。

## 常见任务示例

**1. 查看当前内核版本**

```bash
uname -r
```

**2. 查看机器硬件架构**

```bash
uname -m
```

## 边界与易混淆点

uname -r 是内核版本，不是发行版版本；发行版信息通常查看 /etc/os-release。
