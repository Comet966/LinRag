# ethtool 检索说明

## 用途与查询表达

查看和设置网卡链路与卸载参数。适用实现：ethtool。

- 网卡是百兆还是千兆。
- 网卡用的什么驱动。
- 关掉 rx 校验卸载。
- 哪块网卡是 eth0。

## 参数与行为

- `-i`：显示驱动名、版本和固件。
- `-S`：显示网卡和驱动的统计计数。
- `-k`：查看校验、分段等卸载状态。
- `-K`：开关卸载功能，如 rx off。
- `-s`：设置速度、双工和自协商。
- `-p`：让网口指示灯闪烁定位。
- `-a`：查看收发暂停帧的状态。

## 常见任务示例

**1. 查看链路速度和双工**

```bash
ethtool eth0
```

**2. 查看驱动与固件版本**

```bash
ethtool -i eth0
```

**3. 让网口灯闪 10 秒定位**

```bash
ethtool -p eth0 10
```

## 边界与易混淆点

依赖网卡驱动实现，虚拟设备常不支持某些选项；改 `-s`、`-K` 会临时影响链路。
