# rpm 检索说明

## 用途与查询表达

直接操作 RPM 包和本地数据库。适用实现：RPM。

- 安装本地 rpm。
- 依赖缺失怎么办。
- 查文件所属包。
- 查看包内文件。

## 参数与行为

- `-ivh 包.rpm`：安装本地 rpm 包。
- `-Uvh 包.rpm`：升级或首次安装。
- `-e 包名`：卸载，用包名而非文件名。
- `-qa`：列出已安装的包。
- `-qf 路径`：查文件所属包。
- `-ql 包名`：列出包内文件。
- `-K 包.rpm`：检查摘要与签名。

## 常见任务示例

**1. 安装本地 rpm 包**

```bash
sudo rpm -ivh ./tool-1.2-1.x86_64.rpm
```

**2. 查命令属于哪个包**

```bash
rpm -qf /usr/sbin/sshd
```

**3. 校验包签名**

```bash
rpm -K ./tool-1.2-1.x86_64.rpm
```

## 边界与易混淆点

rpm 不联网、不解决依赖，缺依赖用 yum 或 dnf；-e 只接受包名，不接受文件名。
