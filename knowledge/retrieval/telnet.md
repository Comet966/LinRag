# telnet 检索说明

## 用途与查询表达

远程登录主机或探测端口连通性。适用实现：telnet。

- 测试端口通不通。
- telnet 连不上。
- 明文登录不安全。
- telnet 的用法。

## 参数与行为

- `-8`：允许传输 8 位字符
- `-l`：指定登录的远端用户名
- `-e`：设置转义字符，默认 `^]`
- `-E`：禁用转义字符
- `-K`：不自动登录远端主机
- `-d`：打开调试模式

## 常见任务示例

**1. 测试目标端口是否可达**

```bash
telnet 192.0.2.10 80
```

**2. 用指定用户登录远端**

```bash
telnet -l admin 192.0.2.10
```

**3. 允许 8 位字符登录**

```bash
telnet -8 192.0.2.10
```

## 边界与易混淆点

全程明文，登录请用 `ssh`；测端口时连上即说明开放，退出先按 `Ctrl+]` 再输入 quit。
