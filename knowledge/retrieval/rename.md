# rename 检索说明

## 用途与查询表达

按字面串替换的方式批量改写文件名。适用实现：util-linux。

- 批量改文件名。
- 改文件后缀。
- 批量加前缀。
- 批量补零改名。

## 参数与行为

- `-v`：打印每个改名结果。
- `-n`：只演示，不真正改名。
- `-a`：替换所有匹配，不只第一个。
- `-l`：只替换最后一次匹配。
- `-s`：作用在符号链接目标上。
- `-V`：显示版本，可分辨实现。

## 常见任务示例

**1. 把 txt 后缀批量改成 md**

```bash
rename -v .txt .md *.txt
```

**2. 先试运行看清改名结果**

```bash
rename -n foo foo0 foo?
```

**3. 把文件名前缀转成小写**

```bash
rename -v IMG img IMG_*.jpg
```

## 边界与易混淆点

util-linux 版是 `rename 表达式 替换 文件`，按字面串替换；Perl 版是正则 `s///`，用 `rename -V` 分辨。
