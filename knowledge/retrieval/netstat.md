# netstat 检索说明

## 用途与查询表达

查看网络连接与监听端口。适用实现：net-tools。

- 谁占着 8080 端口。
- 本机监听哪些端口。
- 查看当前 TCP 连接。
- 怎么看本机路由表。

## 参数与行为

- `-a`：显示所有套接字。
- `-l`：只显示监听中的套接字。
- `-t`：只看 TCP 连接。
- `-n`：用数字显示地址和端口。
- `-p`：显示占用进程的 PID 与名称。
- `-r`：显示内核路由表。

## 常见任务示例

**1. 查看监听端口与进程**

```bash
netstat -tlnp
```

**2. 查看全部连接**

```bash
netstat -an
```

**3. 查看路由表**

```bash
netstat -rn
```

## 边界与易混淆点

netstat 属 net-tools，已被 `ss` 和 `ip route` 取代，只看监听要加 `-l`。
