# getfacl 检索说明

## 用途与查询表达

查看文件和目录的访问控制列表。适用实现：acl。

- 查看文件 ACL。
- acl 里都有谁。
- 权限位之外的授权。
- 递归查看目录 acl。

## 参数与行为

- `-c`：省略注释头，只看条目。
- `-d`：只显示默认 ACL。
- `-R`：递归处理子目录。
- `-t`：表格形式，含默认 ACL。
- `-n`：显示数字 UID 和 GID。
- `-p`：保留路径的前导斜杠。

## 常见任务示例

**1. 查看文件的 ACL 条目**

```bash
getfacl report.txt
```

**2. 省略注释头只看条目**

```bash
getfacl -c report.txt
```

**3. 递归查看目录 ACL**

```bash
getfacl -R /srv/share
```

## 边界与易混淆点

只读查看，修改要用 `setfacl`；没有 ACL 时显示的是传统权限位对应的三条基本项。
