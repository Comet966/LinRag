# jobs 检索说明

## 用途与查询表达

列出当前 shell 的作业状态。适用实现：Bash 内建。

- 看后台任务。
- 后台程序列表。
- 哪个任务停了。
- 查作业号。

## 参数与行为

- `-l`：在作业信息中附上 PID。
- `-n`：只列状态有变化的作业。
- `-p`：只列出作业的 PID。
- `-r`：只显示运行中的作业。
- `-s`：只显示已停止的作业。
- `-x`：把命令中的作业号换成 PID。

## 常见任务示例

**1. 列出全部作业及其 PID**

```bash
jobs -l
```

**2. 只看运行中的作业**

```bash
jobs -r
```

**3. 用作业号拼出命令执行**

```bash
jobs -x echo %1
```

## 边界与易混淆点

`jobs` 是 bash 内建，只认当前 shell 的作业，看不到别的终端；全系统用 `ps`。
