# unlink 检索说明

## 用途与查询表达

删除单个文件，不进回收站。适用实现：GNU coreutils。

- 删掉一个文件。
- 怎么彻底删除。
- 为什么删不掉目录。
- 误删能恢复吗。

## 参数与行为

- `--help`：显示帮助信息。
- `--version`：显示版本号。
- `--`：结束选项解析。
- `FILE`：要删除的那一个文件。
- 不接受多文件或目录，无递归。

## 常见任务示例

**1. 删除 /tmp 测试文件**

```bash
unlink /tmp/demo-old.log
```

**2. 先确认路径再删除**

```bash
ls -l /tmp/demo.tmp && unlink /tmp/demo.tmp
```

## 边界与易混淆点

只删一个文件且不可恢复，不支持目录、通配符和多文件；批量或递归请改用 `rm`。
