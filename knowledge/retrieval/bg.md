# bg 检索说明

## 用途与查询表达

把暂停的作业放回后台运行。适用实现：Bash 内建。

- 暂停的作业继续跑。
- 把任务放后台。
- 和 & 的区别。
- 作业号怎么写。

## 参数与行为

- `%1`：按作业号放回后台运行。
- `%%`：当前作业，也可写 `%+`。
- `%-`：上一个作业。
- `%?str`：按命令行字符串匹配作业。
- `bg`：不给作业号时用当前作业。

## 常见任务示例

**1. 把暂停的作业 1 放回后台**

```bash
bg %1
```

**2. 恢复最近暂停的那个作业**

```bash
bg
```

**3. 用命令名匹配再恢复**

```bash
bg %?sleep
```

## 边界与易混淆点

Bash 作业控制内建，不是独立程序；需 `set -m`，只对已暂停作业有效。
