# join 检索说明

## 用途与查询表达

按共同字段合并两个已排序文本。适用实现：GNU coreutils。

- 两文件按列合并。
- 类似 SQL 连接。
- 按 key 拼文件。
- 合并两张表。

## 参数与行为

- `-t`：指定字段分隔符。
- `-1 N`：指定文件 1 的连接字段。
- `-2 N`：指定文件 2 的连接字段。
- `-a N`：同时输出该文件未匹配行。
- `-v N`：只输出该文件未匹配行。
- `-e`：用指定字符串填补空字段。
- `-o`：自定义输出的字段列表。

## 常见任务示例

**1. 按第一列合并两个文件**

```bash
join names.txt cities.txt
```

**2. 换分隔符并按指定列连接**

```bash
join -t ':' -1 2 -2 1 users.txt groups.txt
```

**3. 保留左边没有匹配的行**

```bash
join -a 1 names.txt cities.txt
```

## 边界与易混淆点

两个文件都必须先按连接字段排好序，否则输出错乱；可用 `sort` 预处理。
