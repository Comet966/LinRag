# md5sum 检索说明

## 用途与查询表达

计算或核对文件的 MD5 摘要。适用实现：GNU coreutils。

- 校验文件完整性。
- 生成 md5 值。
- 校验失败怎么办。
- 摘要算法怎么选。

## 参数与行为

- `-c`：按清单核对摘要。
- `--quiet`：只输出校验失败项。
- `--status`：不输出，只用退出码。
- `-b`：以二进制模式读取。
- `--tag`：输出 BSD 风格摘要。

## 常见任务示例

**1. 生成校验和清单**

```bash
md5sum app.tar.gz > app.tar.gz.md5
```

**2. 按清单核对文件**

```bash
md5sum -c app.tar.gz.md5
```

**3. 只显示失败项**

```bash
md5sum -c --quiet app.tar.gz.md5
```

## 边界与易混淆点

MD5 只适合发现传输损坏，摘要一致不等于签名验证；清单路径相对当前目录。
