# nc 检索说明

## 用途与查询表达

TCP/UDP 连接、监听与端口探测。适用实现：netcat-openbsd。

- 端口通不通怎么测。
- 临时开端口收数据。
- 两机之间快速传文件。
- 扫一段端口看哪些开。

## 参数与行为

- `-z`：只扫描端口，不发送数据。
- `-v`：显示连接过程与端口状态。
- `-l`：监听模式，等待对方连接。
- `-u`：改用 UDP 传输。
- `-w N`：连接或响应超时秒数。
- `-n`：不做域名解析。

## 常见任务示例

**1. 探测单个端口是否开放**

```bash
nc -zv -w 2 example.com 80
```

**2. 扫描一段端口范围**

```bash
nc -zv -w 2 192.0.2.10 1-1024
```

**3. 监听端口接收占位数据**

```bash
nc -l -p 8888 > /tmp/nc-recv.bin
```

## 边界与易混淆点

openbsd 版没有 `-e`/`-c`，traditional 版才有；`-z` 须配 `-v` 否则无输出，UDP 扫描结果不可靠。
