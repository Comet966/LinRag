# setsid 检索说明

## 用途与查询表达

在新会话中运行程序。适用实现：util-linux。

- 脱离终端运行。
- 后台运行脚本。
- 会话与进程组。
- 守护进程调试。

## 参数与行为

- `-f`：总是 fork，命令转入后台。
- `-w`：等待命令结束并返回其状态。
- `-c`：把当前终端设为控制终端。
- `--help`：显示帮助信息。
- `--version`：显示版本信息。

## 常见任务示例

**1. 后台脱离终端运行脚本**

```bash
setsid -f /tmp/demo.sh
```

**2. 前台等待命令结束再返回**

```bash
setsid -w sleep 5
```

## 边界与易混淆点

setsid 只脱离终端和会话，不做重定向等守护化；-f 转后台，-w 才等返回码。
