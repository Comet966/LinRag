# strace 检索说明

## 用途与查询表达

跟踪进程系统调用与信号。适用实现：strace。

- 系统调用跟踪。
- 命令卡在哪。
- 附加到进程。
- 统计调用耗时。

## 参数与行为

- `-f`：跟随 fork 出的子进程。
- `-p PID`：附加到已运行的进程。
- `-e trace=SET`：只跟踪指定系统调用。
- `-o FILE`：结果写入文件而非 stderr。
- `-c`：统计调用次数与耗时。
- `-T`：显示每次调用耗时。
- `-s N`：限制字符串显示长度。

## 常见任务示例

**1. 统计命令的系统调用耗时**

```bash
strace -c /bin/true
```

**2. 只看文件相关的系统调用**

```bash
strace -e trace=file ls /tmp
```

## 边界与易混淆点

默认输出到 stderr，用 -o 才写文件；-f 跟子进程；-p 常需 root 或 ptrace 权限。
