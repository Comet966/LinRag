# diff 检索说明

## 用途与查询表达

逐行比较文本文件并显示差异。适用实现：GNU diffutils。

- 比较两个文件。
- 查看配置变更。
- 目录差异。
- 生成补丁文本。

## 参数与行为

- `-u`：使用统一差异格式。
- `-r`：递归比较目录。
- `-q`：只报告文件是否不同。
- `-i`：比较时忽略大小写。
- `-w`：忽略空白差异。

## 常见任务示例

**1. 以统一格式查看两个配置文件的差别**

```bash
diff -u old.conf new.conf
```

**2. 递归比较两个目录，只报告不同文件**

```bash
diff -qr old-dir/ new-dir/
```

## 边界与易混淆点

退出码 0 表示相同，1 表示有差异，大于 1 表示出错；存在差异不等于命令执行失败。
