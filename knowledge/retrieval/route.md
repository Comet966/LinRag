# route 检索说明

## 用途与查询表达

查看和设置内核中的静态路由表。适用实现：net-tools。

- 查看路由表。
- 默认网关在哪。
- 路由表怎么读。
- 没有 route 命令。

## 参数与行为

- `-n`：不解析主机名，显示数字。
- `-e`：显示扩展信息，如 MTU。
- `-ee`：再叠加一层，输出更多列。
- `-A inet`：指定地址族，如 inet6。
- `-v`：详细模式输出。
- `-F`：操作内核 FIB 表，默认。

## 常见任务示例

**1. 数字形式查看路由表**

```bash
route -n
```

**2. 只看默认路由那一行**

```bash
route -n | grep '^0.0.0.0'
```

**3. 显示接口与 MTU 字段**

```bash
route -n -ee
```

## 边界与易混淆点

属于已停维护的 net-tools，新系统用 `ip route`；`route add` 重启即失效。
