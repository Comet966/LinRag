# objdump 检索说明

## 用途与查询表达

查看目标文件与可执行文件内部结构。适用实现：binutils。

- 看二进制的节区。
- 反汇编一段代码。
- 找符号表和重定位。
- 和 nm 有区别吗。

## 参数与行为

- `-h`：列出各节的头部摘要。
- `-d`：反汇编可执行代码节。
- `-t`：显示符号表入口。
- `-r`：显示重定位入口。
- `-s`：显示指定节的完整内容。
- `-C`：把符号名还原成 C++ 名。
- `-S`：反汇编并穿插源码，隐含 `-d`。

## 常见任务示例

**1. 看二进制里有哪些节**

```bash
objdump -h /bin/ls
```

**2. 反汇编并还原 C++ 符号**

```bash
objdump -d -C /bin/ls
```

**3. 只看符号表**

```bash
objdump -t /bin/ls
```

## 边界与易混淆点

`-j` 只筛选节区，需配 `-d`、`-s` 等才有输出；看 ELF 头用 readelf。
