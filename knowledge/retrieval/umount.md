# umount 检索说明

## 用途与查询表达

卸载已挂载的文件系统。适用实现：util-linux。

- 怎么卸载 U 盘。
- 卸载提示忙。
- 谁占用挂载点。
- 强制卸载挂载点。

## 参数与行为

- `umount DIR`：按挂载点卸载。
- `-l`：延迟卸载，先脱离目录树。
- `-f`：强制卸载，多用于 NFS。
- `-r`：失败时改为只读重挂。
- `-t TYPE`：只卸载指定类型。
- `-R`：递归卸载子挂载。
- `-d`：同时分离 loop 设备。

## 常见任务示例

**1. 卸载 U 盘挂载点**

```bash
sudo umount /mnt/usb
```

**2. 查看谁占用挂载点**

```bash
sudo fuser -vm /mnt/usb
```

**3. 挂载点忙时延迟卸载**

```bash
sudo umount -l /mnt/usb
```

## 边界与易混淆点

卸载前先关掉占用进程；按挂载点卸载比按设备名可靠。
