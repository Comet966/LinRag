# pwd 检索说明

## 用途与查询表达

显示当前工作目录的绝对路径。适用实现：Bash / GNU coreutils。

- 我在哪个目录。
- 获取工作路径。
- 解析当前目录的软链接。

## 参数与行为

- `-L`：使用逻辑路径，保留路径中的符号链接名称。
- `-P`：使用物理路径，解析符号链接。

## 常见任务示例

**1. 显示当前目录的实际路径**

```bash
pwd -P
```

**2. 保留符号链接名称，查看逻辑工作路径**

```bash
pwd -L
```

## 边界与易混淆点

Bash 内建 pwd 与外部 pwd 的默认行为可能不同；显式指定 -L 或 -P。
