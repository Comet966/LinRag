# less 检索说明

## 用途与查询表达

分页浏览文本，支持前后翻页和搜索。适用实现：less。

- 大文件翻页阅读。
- 在日志中搜索。
- 查看带颜色的输出。

## 参数与行为

- `-N`：显示行号。
- `-S`：长行不折行，可横向滚动。
- `-i`：搜索时忽略大小写，但模式含大写字母时例外。
- `-R`：显示允许的颜色等转义序列。

## 常见任务示例

**1. 分页查看日志并显示行号**

```bash
less -N app.log
```

**2. 查看宽表格，保留长行以便横向滚动**

```bash
less -S report.tsv
```

## 边界与易混淆点

打开后按 / 输入搜索词，n 查下一个，q 退出。-i 是小写字母 i，不是 -l。
