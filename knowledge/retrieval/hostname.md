# hostname 检索说明

## 用途与查询表达

显示或临时设置主机名。适用实现：hostname 软件包。

- 查看主机名。
- 查看完整域名。
- 查看本机所有 IP。
- 临时修改主机名。

## 参数与行为

- `-s`：显示短主机名。
- `-f`：显示 FQDN。
- `-i`：显示解析到的 IP。
- `-I`：显示所有网络地址。
- `NEWNAME`：临时设置主机名。

## 常见任务示例

**1. 查看当前主机名**

```bash
hostname
```

**2. 查看本机所有 IP**

```bash
hostname -I
```

## 边界与易混淆点

设置是临时的，重启后失效；永久修改用 `hostnamectl`。
