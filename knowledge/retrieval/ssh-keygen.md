# ssh-keygen 检索说明

## 用途与查询表达

生成与管理 SSH 密钥。适用实现：OpenSSH。

- 生成密钥对。
- 查看公钥指纹。
- 修改密钥注释。
- 密钥类型选择。

## 参数与行为

- `-t TYPE`：指定密钥类型，如 ed25519。
- `-b BITS`：指定密钥位数。
- `-C TEXT`：为公钥添加注释。
- `-f FILE`：指定密钥保存路径。
- `-N PASS`：设置或置空口令。
- `-l`：显示公钥指纹。
- `-y`：从私钥导出公钥。

## 常见任务示例

**1. 生成测试密钥到 /tmp**

```bash
ssh-keygen -t ed25519 -f /tmp/demo_key -N ''
```

**2. 查看公钥指纹确认类型**

```bash
ssh-keygen -lf /tmp/demo_key.pub
```

## 边界与易混淆点

私钥要 600 且不得外泄；-y 输出同属敏感内容，只有公钥适合分发。
