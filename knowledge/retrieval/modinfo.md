# modinfo 检索说明

## 用途与查询表达

查看内核模块的描述、参数与路径。适用实现：kmod。

- 看模块详情。
- 模块有哪些参数。
- 模块文件在哪。
- 模块作者和许可。

## 参数与行为

- `-n`：只显示模块文件路径。
- `-a`：只显示作者。
- `-d`：只显示描述。
- `-l`：只显示许可证。
- `-p`：只显示模块参数。
- `-F FIELD`：只显示指定字段。
- `-0`：字段之间用 NUL 分隔。

## 常见任务示例

**1. 查看模块的全部信息**

```bash
modinfo ext4
```

**2. 只看模块文件路径**

```bash
modinfo -n ext4
```

**3. 只列出模块参数**

```bash
modinfo -p ext4
```

## 边界与易混淆点

`modinfo` 只读模块文件，不加载模块；`-n` 给路径，真正加载要用 `modprobe`。
