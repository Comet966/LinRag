# dirname 检索说明

## 用途与查询表达

去掉路径最后一段，输出目录部分。适用实现：GNU coreutils。

- 从路径取目录。
- dirname 怎么用。
- 脚本取自身目录。
- 取路径的上级目录。

## 参数与行为

- `路径...`：一个或多个路径。
- `-z`：用 NUL 分隔输出。
- `--`：结束选项解析。
- `--help`：显示帮助。
- `"$(dirname "$0")"`：脚本取自身目录。

## 常见任务示例

**1. 取文件的目录**

```bash
dirname /var/log/syslog
```

**2. 忽略尾部斜杠**

```bash
dirname /var/log/
```

**3. 脚本取自身目录**

```bash
script_dir=$(dirname "$0")
```

## 边界与易混淆点

dirname 只切字符串，不解析 .. 或符号链接；无目录时输出 .。
