# killall 检索说明

## 用途与查询表达

按进程名向一组同名进程发信号。适用实现：psmisc。

- 按名字杀进程。
- 杀同名多个进程。
- kill 找不到进程。
- 进程还在不在。

## 参数与行为

- `-l`：列出所有信号名称。
- `-I`：匹配进程名时忽略大小写。
- `-e`：要求进程名完全匹配。
- `-s`：指定要发送的信号。
- `-u`：只处理指定用户的进程。
- `-i`：发送前逐个交互确认。

## 常见任务示例

**1. 列出可用信号名称**

```bash
killall -l
```

**2. 只探测进程是否存在**

```bash
killall -0 nginx
```

**3. 精确匹配进程名再探测**

```bash
killall -0 -e nginx
```

## 边界与易混淆点

`killall` 按进程名批量命中，与按 PID 的 `kill` 不同；不确定先用 `-0` 试探。
