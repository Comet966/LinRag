# users 检索说明

## 用途与查询表达

列出当前登录的用户名。适用实现：GNU coreutils。

- 谁登录了这台机器。
- 有哪些用户在线。
- 同一用户为何重复。
- 和 who 有什么区别。

## 参数与行为

- `--help`：显示帮助信息。
- `--version`：显示版本号。
- `FILE`：改用指定的记录文件。
- `--`：结束选项解析。
- 每个登录会话都输出一次用户名。

## 常见任务示例

**1. 谁登录了这台机器**

```bash
users
```

**2. 统计登录会话数**

```bash
users | wc -w
```

## 边界与易混淆点

只输出用户名，不含终端与登录时间；要看详情用 `who` 或 `w`，去重可接 `sort -u`。
