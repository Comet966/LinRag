# cal 检索说明

## 用途与查询表达

显示月历或年历，默认本月。适用实现：util-linux。

- 查看本月日历。
- 显示全年日历。
- 一周从周一开始。
- 查看指定年月。

## 参数与行为

- `-1`：只显示单月，缺省。
- `-3`：显示上月、本月、下月。
- `-y`：显示当前年份全年。
- `-m`：以周一为一周第一天。
- `-s`：以周日为一周第一天。
- `-j`：显示儒略日，即年内序号。

## 常见任务示例

**1. 查看本月日历**

```bash
cal
```

**2. 查看前后三个月**

```bash
cal -3
```

**3. 指定年月并用周一开头**

```bash
cal -m 3 2024
```

## 边界与易混淆点

只打印日历，不读日程；年份要写全，`cal 89` 是公元 89 年而非 1989 年。
