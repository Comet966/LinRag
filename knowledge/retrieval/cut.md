# cut 检索说明

## 用途与查询表达

按字段、字节或字符位置提取每行内容。适用实现：GNU coreutils。

- 提取某列。
- 分隔符切分文本。
- 输出用户名字段。

## 参数与行为

- `-d CHAR`：指定字段分隔符，默认制表符。
- `-f LIST`：提取指定字段，编号从 1 开始。
- `-b LIST`：提取指定字节位置。
- `-c LIST`：提取指定字符位置，多字节支持取决于版本。
- `-s`：字段模式下跳过不含分隔符的行。

## 常见任务示例

**1. 提取用户记录的第一列**

```bash
cut -d ':' -f 1 /etc/passwd
```

**2. 提取制表符分隔表格的第一列和第三列**

```bash
cut -f 1,3 report.tsv
```

## 边界与易混淆点

不解析带引号和转义的 CSV；使用 -d 时连续分隔符不会自动合并，复杂字段处理适合 awk。旧版 GNU cut 的 -c 可能按字节处理；新版本已提供多字节支持，处理中文时先确认版本。
