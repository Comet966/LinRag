# 7z 检索说明

## 用途与查询表达

创建和解开 7z 等压缩包。适用实现：p7zip。

- 解压 7z 压缩包。
- 查看压缩包内容。
- 指定解压目录。
- 加密压缩包怎么解。

## 参数与行为

- `a`：添加文件，创建或更新压缩包。
- `x`：解压并保留原有目录结构。
- `e`：解压但忽略目录结构。
- `l`：只列出压缩包内容。
- `-o{DIR}`：指定输出目录，后不加空格。
- `-p{PASS}`：指定压缩包密码。
- `-mx=N`：压缩级别 0 到 9，9 最慢最小。

## 常见任务示例

**1. 列出压缩包内的文件**

```bash
7z l data.7z
```

**2. 解压到指定目录**

```bash
7z x data.7z -o/tmp/out
```

**3. 最高压缩级别打包目录**

```bash
7z a -mx=9 data.7z /tmp/out
```

## 边界与易混淆点

`x` 保留路径、`e` 摊平路径；`-o` 与目录之间不能有空格。
