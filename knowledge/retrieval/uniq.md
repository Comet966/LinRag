# uniq 检索说明

## 用途与查询表达

处理相邻的重复文本行。适用实现：GNU coreutils。

- 统计重复行次数。
- 文本去重。
- 找重复记录。

## 参数与行为

- `-c`：在行前显示出现次数。
- `-d`：只输出重复的行，每组一次。
- `-u`：只输出未重复的行。
- `-i`：比较时忽略大小写。

## 常见任务示例

**1. 统计每个名字出现的次数**

```bash
sort names.txt | uniq -c
```

**2. 找出排序后重复出现的记录，每组输出一次**

```bash
sort names.txt | uniq -d
```

## 边界与易混淆点

只合并相邻重复行；全文件去重通常先 sort。-u 只保留出现一次的组，不是每组留一个。
