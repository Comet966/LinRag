# ping 检索说明

## 用途与查询表达

测试到目标主机的连通性。适用实现：iputils。

- 网络通不通怎么测。
- ping 不通是断网吗。
- 让 ping 发几个包。
- 怎么看丢包率。

## 参数与行为

- `-c N`：发 N 个包后退出。
- `-i SEC`：设置发包间隔秒数。
- `-W SEC`：单包回应超时秒数。
- `-w SEC`：本次总超时秒数。
- `-I IFACE`：指定出口接口。
- `-n`：只输出数字地址。
- `-q`：只输出统计摘要。

## 常见任务示例

**1. 测连通性，发 4 个包**

```bash
ping -c 4 example.com
```

**2. 限制总耗时**

```bash
ping -c 5 -w 3 example.com
```

**3. 只看结尾统计**

```bash
ping -q -c 10 example.com
```

## 边界与易混淆点

ping 走 ICMP，防火墙常丢弃，不通不代表端口不可用，`-c` 不加会一直发。
