# ltrace 检索说明

## 用途与查询表达

跟踪进程对库函数的调用。适用实现：ltrace。

- 跟踪程序库调用。
- 统计库调用耗时。
- 和 strace 区别。
- 附加到进程跟踪。

## 参数与行为

- `-c`：统计各调用次数与耗时。
- `-f`：同时跟踪子进程。
- `-e FILTER`：只跟踪匹配的函数。
- `-p PID`：附加到运行中的进程。
- `-S`：同时显示系统调用。
- `-T`：显示每次调用的耗时。
- `-o FILE`：把输出写入文件。

## 常见任务示例

**1. 统计程序的库调用与耗时**

```bash
ltrace -c /bin/ls
```

**2. 跟踪子进程并写入日志**

```bash
ltrace -f -o /tmp/ltrace.log /bin/ls
```

**3. 附加到占位 PID 的进程**

```bash
ltrace -p 1234
```

## 边界与易混淆点

只跟踪动态链接程序的库调用，静态程序看不到；系统调用要用 `strace`。
