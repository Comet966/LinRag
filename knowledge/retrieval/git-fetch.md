# git fetch 检索说明

## 用途与查询表达

从远程下载对象并更新远程跟踪引用。适用实现：Git 2.23+。

- 更新远程分支信息。
- 只下载不合并。
- 查看远程最新提交前同步引用。

## 参数与行为

- `--all`：获取所有已配置远程。
- `--prune`：清理远程已删除分支的本地跟踪引用。
- `--tags`：获取标签。
- `--dry-run`：显示操作但不更新。

## 常见任务示例

**1. 获取 origin 最新状态**

```bash
git fetch origin
```

**2. 预览获取和清理操作**

```bash
git fetch --dry-run --prune origin
```

**3. 获取全部远程**

```bash
git fetch --all
```

## 边界与易混淆点

fetch 通常不合并到当前分支，也不修改工作区；--prune 清理的是远程跟踪引用。
