# groups 检索说明

## 用途与查询表达

打印用户所属的组名列表。适用实现：GNU coreutils。

- 查用户在哪些组。
- 用户属于哪个组。
- 与 id -Gn 等价。
- 当前用户的所有组。

## 参数与行为

- `--help`：显示帮助信息。
- `--version`：显示版本信息。
- `用户名`：省略时为当前用户。
- `id -Gn`：等价写法，结果相同。
- 其余：不接受其他命令行选项。

## 常见任务示例

**1. 查看当前用户所属组**

```bash
groups
```

**2. 查询指定用户的组**

```bash
groups alice
```

**3. 与 id -Gn 对照确认**

```bash
groups alice && id -Gn alice
```

## 边界与易混淆点

读的是用户组数据库，不反映 `newgrp` 临时切换；组名列表等价于 `id -Gn`。
