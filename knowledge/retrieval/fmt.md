# fmt 检索说明

## 用途与查询表达

把文本段落重排到指定列宽。适用实现：GNU coreutils。

- 文本按宽度重排。
- 段落重新折行。
- 只拆行不合并。
- 和 fold 有何区别。

## 参数与行为

- `-w 72`：设定每行最大列宽。
- `-s`：只拆长行，不合并短行。
- `-u`：词间单空格，句末双空格。
- `-c`：保留段首两行的缩进。
- `-t`：按段首缩进区分标记段。
- `-p STR`：只合并以 STR 开头的行。

## 常见任务示例

**1. 按 72 列重排文本**

```bash
fmt -w 72 note.txt
```

**2. 只拆分长行不合并**

```bash
fmt -s -w 60 note.txt
```

**3. 统一空格与句距**

```bash
fmt -u -w 72 note.txt
```

## 边界与易混淆点

只重排段落内部换行，不改正文内容；跨段请留空行，否则会被并成一段。
