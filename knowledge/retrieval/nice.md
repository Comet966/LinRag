# nice 检索说明

## 用途与查询表达

调整进程调度优先级后运行命令。适用实现：GNU coreutils。

- 让任务少抢 CPU。
- nice 值怎么看。
- 为什么优先级设不上。
- 和 renice 差异。

## 参数与行为

- `-n 值`：设 nice 值，越小优先级越高。
- `-数值`：旧写法，等价于 `-n` 数值。
- `--adjustment=值`：同 `-n`，长选项写法。
- `--help`：显示帮助后退出。
- `--version`：显示版本信息。

## 常见任务示例

**1. 查看当前的 nice 值**

```bash
nice
```

**2. 以最低优先级做耗时统计**

```bash
nice -n 19 du -sh /var/log
```

**3. 调高优先级需要 root**

```bash
sudo nice -n -5 ps aux
```

## 边界与易混淆点

不写 `-n` 时在当前值上再加 10；调低数值需 root，只影响新进程。
