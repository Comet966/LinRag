# rmmod 检索说明

## 用途与查询表达

从内核中卸载已加载的模块。适用实现：kmod。

- 卸载内核模块。
- 模块占用卸不掉。
- 移除驱动模块。
- 查看模块是否占用。

## 参数与行为

- `-v`：打印更多卸载过程信息。
- `-s`：把错误信息发给 syslog。
- `-f`：强制卸载，可能直接崩溃。
- `-h`：显示帮助后退出。
- `-V`：显示版本信息。

## 常见任务示例

**1. 先看模块是否被占用**

```bash
lsmod | grep -w raid1
```

**2. 卸载指定内核模块**

```bash
rmmod -v raid1
```

**3. 试运行看依赖怎么处理**

```bash
modprobe -n -r raid1
```

## 边界与易混淆点

需 root；模块被占用时卸载失败，`-f` 强卸有崩溃风险。kmod 版无 `-w`，可改用 `modprobe -r`。
