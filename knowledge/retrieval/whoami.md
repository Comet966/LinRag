# whoami 检索说明

## 用途与查询表达

显示当前有效用户的名称。适用实现：GNU coreutils。

- 我现在是什么用户。
- sudo 后身份。
- 当前有效用户名。

## 参数与行为

- `--help`：显示帮助。
- `--version`：显示版本。

## 常见任务示例

**1. 确认当前命令以哪个用户身份运行**

```bash
whoami
```

**2. 通过 sudo 启动子命令，确认其有效用户（需相应权限）**

```bash
sudo -u alice whoami
```

## 边界与易混淆点

等价于 id -un 的用途；不能用来确定最初登录者，提权或切换用户后身份可能改变。
