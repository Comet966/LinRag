# batch 检索说明

## 用途与查询表达

系统不忙时执行一次性任务。适用实现：at。

- 空闲时执行任务。
- 和 at 有何不同。
- 降低负载跑脚本。
- 任务不立即执行。

## 参数与行为

- `-f FILE`：从文件读取要执行的命令。
- `-m`：结束后给用户发邮件。
- `-q Q`：指定队列，默认 b 队列。
- `-v`：显示任务预计执行时间。
- `TIME`：可选的最早执行时间。
- `-V`：只显示版本号。

## 常见任务示例

**1. 系统空闲时运行脚本**

```bash
batch -f /tmp/report.sh
```

**2. 一小时后才允许执行**

```bash
batch -f /tmp/report.sh now + 1 hour
```

**3. 查看 b 队列排队情况**

```bash
atq -q b
```

## 边界与易混淆点

本质是 `at` 的 b 队列，负载降到阈值以下才运行，开始时间不保证。
