# rg 检索说明

## 用途与查询表达

快速递归搜索文件内容，默认遵循忽略规则。适用实现：ripgrep。

- ripgrep 搜索代码。
- 快速递归查字符串。
- 按扩展名过滤搜索。

## 参数与行为

- `-n`：显示行号。
- `-i`：忽略大小写。
- `-F`：按固定字符串匹配。
- `-g GLOB`：按路径模式筛选文件。
- `--hidden`：包括隐藏路径。
- `--files`：列出候选文件。

## 常见任务示例

**1. 搜索代码目录中的字符串**

```bash
rg -n 'TODO' src/
```

**2. 只搜索 Python 文件**

```bash
rg -n -g '*.py' 'def main' .
```

**3. 按固定字符串搜索**

```bash
rg -F '127.0.0.1' config/
```

## 边界与易混淆点

默认跳过隐藏文件和被忽略的路径，且跳过二进制文件内容；--hidden 本身不取消 gitignore 规则，rg 需要单独安装。
