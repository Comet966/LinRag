# sar 检索说明

## 用途与查询表达

按间隔采样并报告系统各项资源统计。适用实现：sysstat。

- 看历史 CPU 负载。
- 内存使用统计。
- 网卡流量统计。
- 系统性能回溯。

## 参数与行为

- `-u`：CPU 利用率统计。
- `-r`：内存使用率统计。
- `-b`：磁盘 I/O 速率。
- `-d`：块设备活动统计。
- `-n DEV`：网卡流量统计。
- `-P ALL`：每个 CPU 分别统计。
- `-f 文件`：读历史 sa 数据文件。

## 常见任务示例

**1. 每秒采样 CPU 共三次**

```bash
sar -u 1 3
```

**2. 查看内存使用情况**

```bash
sar -r 1 3
```

**3. 读取历史采样文件**

```bash
sar -u -f /var/log/sa/sa20
```

## 边界与易混淆点

间隔与次数是位置参数；`-f` 读 `sadc` 日文件，需 sysstat 定时采集才有数据。
