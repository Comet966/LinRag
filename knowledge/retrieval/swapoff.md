# swapoff 检索说明

## 用途与查询表达

关闭指定交换分区或交换文件。适用实现：util-linux。

- 怎么关掉交换区。
- 停用交换文件。
- swap 关不掉。
- swapoff 的用法。

## 参数与行为

- `-a`：关闭所有已知交换区
- `-v`：打印正在关闭的交换区
- `-h`：显示帮助信息
- `-V`：显示版本信息
- `<交换区>`：要关闭的分区设备或文件

## 常见任务示例

**1. 先看帮助，避免误停交换区**

```bash
swapoff -h
```

**2. 确认版本，不改任何状态**

```bash
swapoff -V
```

## 边界与易混淆点

没有 dry-run，执行即停用交换区；可先用 `swapon --show` 确认，再用 `swapon -a` 恢复。
