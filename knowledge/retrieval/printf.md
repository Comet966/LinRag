# printf 检索说明

## 用途与查询表达

按格式串格式化输出。适用实现：Bash 内建 / GNU coreutils。

- 格式化输出字符串。
- printf 保留小数。
- 对齐打印表格。
- printf 有何不同。

## 参数与行为

- `-v 变量`：结果存入变量不打印。
- `%s`：输出字符串。
- `%d`：输出整数。
- `%f`：输出浮点数。
- `%q`：转成可回填 shell 的引用。
- `%(FMT)T`：按格式输出时间。

## 常见任务示例

**1. 对齐打印表格**

```bash
printf '%-10s %6s\n' 'name' 'score'
```

**2. 保留两位小数**

```bash
printf '%.2f\n' 3.14159
```

**3. 输出当前时间**

```bash
printf '%(%Y-%m-%d %H:%M:%S)T\n' -1
```

## 边界与易混淆点

printf 不自动换行；格式串别拼接用户输入，改用 %s 传值。
