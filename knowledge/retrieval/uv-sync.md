# uv sync 检索说明

## 用途与查询表达

将项目环境同步为锁文件和依赖组要求的状态。适用实现：uv 项目工作流。

- 按 uv.lock 安装依赖。
- uv 同步虚拟环境。
- uv locked 和 frozen 区别。

## 参数与行为

- `--locked`：锁文件需保持最新，否则报错。
- `--frozen`：使用现有锁文件而不检查新鲜度。
- `--no-dev`：排除默认的 dev 依赖组。
- `--inexact`：保留未被项目要求的额外包。

## 常见任务示例

**1. 同步当前项目环境**

```bash
uv sync
```

**2. 要求锁文件已是最新再同步**

```bash
uv sync --locked
```

**3. 不安装默认开发依赖组**

```bash
uv sync --no-dev
```

## 边界与易混淆点

默认精确同步可能移除额外包；locked 检查锁文件是否最新，frozen 跳过这项检查，二者不能混为一谈。
