# modprobe 检索说明

## 用途与查询表达

按依赖关系加载或卸载内核模块。适用实现：kmod。

- 加载内核模块。
- 模块依赖没加载。
- 和 insmod 区别。
- 卸载模块。

## 参数与行为

- `-r`：卸载模块并清理依赖。
- `-D`：只显示依赖，不加载。
- `-n`：干跑，不真正加载。
- `-v`：显示执行过程。
- `-c`：显示最终生效的配置。
- `-q`：出错时不打印提示。

## 常见任务示例

**1. 干跑看加载顺序与依赖**

```bash
modprobe -n -v vfat
```

**2. 只看依赖关系不加载**

```bash
modprobe -D loop
```

**3. 干跑卸载模块及其依赖**

```bash
modprobe -n -r vfat
```

## 边界与易混淆点

`modprobe` 用模块名并自动解析依赖，`insmod` 要给 `.ko` 路径且不解决依赖。
