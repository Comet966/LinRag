# chown 检索说明

## 用途与查询表达

修改文件或目录的所有者及所属组。适用实现：GNU coreutils。

- 改变文件归属。
- 修改 owner。
- 递归设置属主。
- 用户组权限。

## 参数与行为

- `-R`：递归处理目录及内容。
- `-h`：修改符号链接本身的属主而非目标。
- `-v`：显示处理信息。
- `-c`：只报告实际改变。
- `--reference=FILE`：使用参考文件的属主和组。

## 常见任务示例

**1. 将文件属主和组设为指定用户与组**

```bash
chown alice:developers report.txt
```

**2. 只修改文件所属组，保持属主不变**

```bash
chown :developers report.txt
```

## 边界与易混淆点

用户和组需实际存在，修改属主通常需要管理员权限；权限位由 chmod 修改，chown 改归属。
