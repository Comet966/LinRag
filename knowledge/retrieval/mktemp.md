# mktemp 检索说明

## 用途与查询表达

安全创建唯一命名的临时文件或目录。适用实现：GNU coreutils。

- 脚本建临时文件。
- 建临时目录。
- 临时文件放哪。
- 拿到唯一文件名。

## 参数与行为

- `-d`：创建临时目录而非文件。
- `-u`：只打印名字不创建，不安全。
- `-p DIR`：在指定目录下创建。
- `-t`：在 $TMPDIR 或 /tmp 下建。
- `--suffix=SUF`：给名字加后缀。
- `-q`：静默，抑制失败提示。

## 常见任务示例

**1. 创建临时文件并取得路径**

```bash
mktemp
```

**2. 创建临时目录**

```bash
mktemp -d
```

**3. 指定目录、模板与后缀**

```bash
mktemp -p /tmp --suffix=.log build.XXXXXX
```

## 边界与易混淆点

`-u` 只给名字不创建文件，有竞态风险；模板末尾至少要三个 `X`。
