# pidstat 检索说明

## 用途与查询表达

按进程查看 CPU、内存、IO 与切换。适用实现：sysstat。

- 哪个进程占 CPU 高。
- 单进程内存变化。
- 进程磁盘读写速度。
- 每 2 秒采样一次。

## 参数与行为

- `-u`：显示 CPU 使用统计，默认项。
- `-r`：显示内存使用统计。
- `-d`：显示磁盘 IO 统计。
- `-w`：显示上下文切换统计。
- `-p`：只统计指定进程号。
- `-t`：细化到线程级统计。
- `-l`：显示完整命令行参数。

## 常见任务示例

**1. 每 2 秒采样 CPU，共 3 次**

```bash
pidstat -u 2 3
```

**2. 只看指定进程的内存**

```bash
pidstat -r -p 1234 1 3
```

**3. 查看线程级 CPU 占用**

```bash
pidstat -t -u 1 2
```

## 边界与易混淆点

首次输出是自开机以来的平均值，之后才是区间值；只做采样统计，不改变进程。
