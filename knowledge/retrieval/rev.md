# rev 检索说明

## 用途与查询表达

把文件每行内容按字符反序输出。适用实现：util-linux。

- 逐行反转文本。
- 字符顺序倒过来。
- 反序查看每行。
- 查文件末字符。

## 参数与行为

- `文件...`：要反序输出的文件，可多个。
- `不给文件参数`：默认从标准输入读取。
- `-0, --zero`：用 NUL 作行分隔符。
- `--`：之后的内容都当作文件名。
- `-h, --help`：显示帮助后退出。
- `-V, --version`：显示版本信息。

## 常见任务示例

**1. 反序查看一行文本**

```bash
echo 'hello world' | rev
```

**2. 逐行反序显示文件内容**

```bash
rev /etc/hosts
```

**3. 反序后接管道继续处理**

```bash
rev access.log | head -n 5
```

## 边界与易混淆点

只反转每行内的字符，行序不变；要反转行序用 `tac`，按字段倒序用 `awk`。
