# cmp 检索说明

## 用途与查询表达

逐字节比较，报首个差异位置。适用实现：GNU diffutils。

- 两个文件是否一样。
- 二进制文件怎么比较。
- 只想要退出码。
- 和大文件比较省略头。

## 参数与行为

- `-l`：列出所有不同字节的偏移。
- `-s`：不输出内容，只看退出码。
- `-b`：同时显示差异处的字符。
- `-c`：打印差异处的字符编码。
- `-i N`：跳过开头 N 个字节再比。
- `-n N`：最多只比较前 N 个字节。

## 常见任务示例

**1. 比较两个文件是否相同**

```bash
cmp a.txt b.txt
```

**2. 列出全部差异字节**

```bash
cmp -l a.txt b.txt
```

**3. 脚本里只用退出码判断**

```bash
cmp -s a.txt b.txt
```

## 边界与易混淆点

逐字节比较，不认文本行，与 `diff` 的行级差异不同；相同则无输出，退出码 0。
