# git add 检索说明

## 用途与查询表达

把文件内容或删除操作写入暂存区。适用实现：Git 2.23+。

- 暂存修改。
- 选择部分代码提交。
- 将新文件加入 Git。

## 参数与行为

- `-A`：暂存整个工作区的新增、修改和删除。
- `-p`：交互选择修改块。
- `-u`：暂存已跟踪文件的修改和删除。
- `--dry-run`：预览将暂存的路径。

## 常见任务示例

**1. 暂存指定文件**

```bash
git add README.md
```

**2. 交互选择代码改动**

```bash
git add -p
```

**3. 预览整个工作区的暂存范围**

```bash
git add --dry-run -A
```

## 边界与易混淆点

add 暂存的是执行时的内容，之后的编辑需再次暂存；-A 可能包含不应提交的文件。
