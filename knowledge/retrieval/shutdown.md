# shutdown 检索说明

## 用途与查询表达

安排关机或重启。适用实现：systemd。

- 定时关机。
- 定时重启。
- 取消关机计划。
- 只广播不关机。

## 参数与行为

- `--help`：显示帮助并退出。
- `-r`：关机后重新启动。
- `-P`：关机并切断电源。
- `-k`：只广播警告，不真关机。
- `-c`：取消已计划的关机。
- `--no-wall`：不向登录用户广播。

## 常见任务示例

**1. 查看参数与时间格式说明**

```bash
shutdown --help
```

**2. 演练：只广播，不真正关机**

```bash
shutdown -k +5 '维护演练'
```

## 边界与易混淆点

默认执行关机，now 立即生效，+5 表示 5 分钟后；-k 仅广播；计划用 -c 取消。
