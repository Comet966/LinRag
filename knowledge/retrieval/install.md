# install 检索说明

## 用途与查询表达

复制文件并设定权限属主，或建目录。适用实现：GNU coreutils。

- 装文件到目录。
- 复制并设权限。
- 建多级目录。
- 装程序进目标目录。

## 参数与行为

- `-m`：设置目标文件的权限模式。
- `-o`：设置属主，通常需 root。
- `-g`：设置属组。
- `-d`：创建目录，类似 `mkdir -p`。
- `-D`：自动补建目标的父目录。
- `-t`：指定目标目录。
- `-v`：显示处理的每个文件。

## 常见任务示例

**1. 一次建好多级目录**

```bash
install -d /tmp/demo/conf
```

**2. 复制并设为 755 权限**

```bash
install -m 755 app.sh /tmp/demo/
```

**3. 补建父目录后复制文件**

```bash
install -D -m 644 app.conf /tmp/demo/etc/app.conf
```

## 边界与易混淆点

`install` 会先删旧目标再新建，硬链接会断；只想覆盖内容就用 `cp`。
