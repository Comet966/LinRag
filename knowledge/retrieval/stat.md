# stat 检索说明

## 用途与查询表达

显示文件或文件系统的详细状态。适用实现：GNU coreutils。

- 查看文件详细信息。
- stat 看修改时间。
- 查看文件权限。
- stat 格式化输出。

## 参数与行为

- `-c 格式`：按格式输出文件信息。
- `--printf=格式`：解释转义且不加换行。
- `-f`：显示文件系统状态。
- `-L`：跟随符号链接。
- `-t`：简洁单行输出。

## 常见任务示例

**1. 查看文件状态**

```bash
stat app.log
```

**2. 输出名称大小时间**

```bash
stat -c '%n %s %y' app.log
```

**3. 查看权限和属主**

```bash
stat -c '%a %U:%G %n' app.log
```

## 边界与易混淆点

stat 只读元数据，不读内容；-c 加换行，--printf 不加。
