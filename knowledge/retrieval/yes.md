# yes 检索说明

## 用途与查询表达

重复输出字符串直到被终止。适用实现：GNU coreutils。

- 一直输出 y。
- 自动回答 yes。
- 怎么只输出几行。
- 连续写测试数据。

## 参数与行为

- `STRING`：要重复输出的文本，默认 y。
- `--help`：显示帮助信息。
- `--version`：显示版本号。
- `--`：结束选项解析。
- 多个字符串按空格拼接后输出。

## 常见任务示例

**1. 只取前 3 行**

```bash
yes | head -n 3
```

**2. 输出自定义文本**

```bash
yes 'ok' | head -n 2
```

## 边界与易混淆点

会无限输出，必须配合 `head` 限行或及时按 `Ctrl+C`，否则可能写满磁盘。
