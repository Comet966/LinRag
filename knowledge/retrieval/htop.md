# htop 检索说明

## 用途与查询表达

交互式进程查看器，可排序过滤。适用实现：htop。

- 图形化看进程。
- 按内存占用排序。
- 只看某个用户进程。
- 比 top 强在哪。

## 参数与行为

- `-u 用户名`：只看该用户的进程。
- `-p PID`：只看指定 PID 的进程。
- `-d 20`：刷新间隔，单位 0.1 秒。
- `-s PID`：按指定列排序显示。
- `-C`：使用单色配色方案。

## 常见任务示例

**1. 打开交互式进程视图**

```bash
htop
```

**2. 只看指定用户的进程**

```bash
htop -u root
```

**3. 每 2 秒刷新一次**

```bash
htop -d 20
```

## 边界与易混淆点

`htop` 是交互式界面，需 ncurses 终端；`-d` 单位是 0.1 秒，脚本采集用 `ps`。
