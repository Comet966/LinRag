# cat 检索说明

## 用途与查询表达

连接文件并把内容输出到标准输出。适用实现：GNU coreutils。

- 显示小文本文件。
- 合并文件内容。
- 检查隐藏控制字符。

## 参数与行为

- `-n`：为所有输出行编号。
- `-b`：只为非空行编号。
- `-s`：将连续空行压缩为一个。
- `-A`：显示不可见字符，包括行尾和制表符。

## 常见任务示例

**1. 查看文件正文及行号**

```bash
cat -n notes.txt
```

**2. 按顺序合并两个文本文件到新的输出文件**

```bash
cat part1.txt part2.txt > combined.txt
```

## 边界与易混淆点

默认完整输出文件，不分页；大文件交互阅读用 less，查看末尾用 tail。
