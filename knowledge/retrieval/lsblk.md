# lsblk 检索说明

## 用途与查询表达

树状列出块设备与分区。适用实现：util-linux。

- 查看磁盘分区。
- 查看分区类型。
- 树状换列表。
- 磁盘挂载在哪。

## 参数与行为

- `-f`：显示文件系统类型和 UUID。
- `-o LIST`：自定义输出列。
- `-l`：改用列表格式。
- `-n`：不输出表头。
- `-d`：只显示磁盘本身。
- `-p`：显示完整设备路径。

## 常见任务示例

**1. 树状查看磁盘分区**

```bash
lsblk
```

**2. 查看文件系统类型**

```bash
lsblk -f
```

**3. 只看某块磁盘**

```bash
lsblk /dev/sda
```

## 边界与易混淆点

查 UUID 用 `-f`；`-d` 不展开分区，`-s` 是反向依赖。
