# dmesg 检索说明

## 用途与查询表达

读取内核环形缓冲区消息。适用实现：util-linux。

- 查看内核消息。
- 时间戳可读化。
- 排查硬件问题。
- 无权限读取。

## 参数与行为

- `-T`：时间戳转为可读时间。
- `-l err`：按级别过滤。
- `-w`：持续输出新消息。
- `-H`：分页并显示相对时间。
- `-x`：解码 facility 和级别。

## 常见任务示例

**1. 查看最近内核消息**

```bash
dmesg -T | tail -n 20
```

**2. 只看错误和警告**

```bash
sudo dmesg -T -l err,warn
```

**3. 排查 USB 设备**

```bash
dmesg -T | grep -i usb
```

## 边界与易混淆点

环形缓冲区会覆盖旧消息；-T 依赖系统时间；dmesg_restrict=1 时普通用户无权读取。
