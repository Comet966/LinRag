# fdisk 检索说明

## 用途与查询表达

查看和修改磁盘分区表。适用实现：util-linux。

- 查看磁盘分区表。
- 磁盘剩余空间怎么看。
- 新建分区怎么操作。
- 分区 UUID 怎么看。

## 参数与行为

- `-l`：列出分区表后退出，只读。
- `-x`：类似 `-l`，显示更多细节。
- `-o LIST`：配合 `-l` 选择输出列。
- `p`：交互模式打印分区表。
- `w`：写入分区表并退出，会改动磁盘。

## 常见任务示例

**1. 列出所有磁盘分区表（只读）**

```bash
sudo fdisk -l
```

**2. 查看指定磁盘的详细分区**

```bash
sudo fdisk -x /dev/sdX
```

## 边界与易混淆点

只改分区表，不建文件系统；`-l`、`-x` 只读，改动按 `w` 才落盘。
