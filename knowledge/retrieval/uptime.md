# uptime 检索说明

## 用途与查询表达

查看运行时间和平均负载。适用实现：procps-ng。

- 系统运行了多久。
- 查看平均负载。
- 负载高不高。
- 查看开机时间。

## 参数与行为

- `-p`：易读格式显示运行时长。
- `-s`：显示系统启动时间。
- `-c`：显示容器运行时间。
- `-r`：输出原始秒数。
- `-V`：显示版本。

## 常见任务示例

**1. 查看运行时间和平均负载**

```bash
uptime
```

**2. 只显示已运行时长**

```bash
uptime -p
```

## 边界与易混淆点

负载含不可中断睡眠进程，不等于 CPU 使用率，也不按核心数归一化。
