# time 检索说明

## 用途与查询表达

统计命令耗时与 CPU 占用。适用实现：Bash 内建 / GNU time。

- 命令跑了多久。
- 比较脚本快慢。
- 看内存峰值。
- 内建和外部区别。

## 参数与行为

- `-p`：使用 POSIX 可移植输出格式
- `-f`：自定义输出格式，如 `%E`
- `-o`：把统计结果写入指定文件
- `-a`：配合 `-o` 追加而不覆盖
- `-v`：输出内存等详细资源用量

## 常见任务示例

**1. 统计一条命令的耗时**

```bash
time ls /usr/bin
```

**2. 外部 time 输出资源详情**

```bash
/usr/bin/time -v sleep 1
```

**3. 把耗时写入文件比较**

```bash
/usr/bin/time -o t.log -f '%E' sleep 1
```

## 边界与易混淆点

Bash 内建的 `time` 只支持 `-p`；`-v`、`-o`、`-f` 只属于 `/usr/bin/time`。
