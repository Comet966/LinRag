# ar 检索说明

## 用途与查询表达

创建和查看静态库归档文件。适用实现：binutils。

- 打包成静态库。
- 查看库里有哪些成员。
- 从库里取出目标文件。
- ar 不做压缩。

## 参数与行为

- `r`：替换或新增成员文件。
- `t`：列出归档中的成员名。
- `x`：把成员解出到当前目录。
- `d`：从归档中删除成员。
- `s`：生成或更新符号索引。
- `v`：配合 `t`、`r` 输出详情。
- `U`：改用真实时间戳和属主。

## 常见任务示例

**1. 把目标文件打包成静态库**

```bash
ar rcs libutil.a add.o sub.o
```

**2. 列出库中的成员文件**

```bash
ar t libutil.a
```

**3. 详细查看成员大小和时间**

```bash
ar tv libutil.a
```

## 边界与易混淆点

只打包不压缩；默认确定性模式把时间戳和属主归零，要保留原值加 `U`。
