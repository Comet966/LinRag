# git 检索说明

## 用途与查询表达

分布式版本控制工具，用于管理代码历史、分支和协作。适用实现：Git 2.23+。

- 版本控制工具。
- 管理代码版本。
- Git 常用命令。

## 参数与行为

- `-C DIR`：在指定目录执行命令。
- `--version`：显示 Git 版本。
- `--help`：显示帮助。

## 常见任务示例

**1. 查看安装版本**

```bash
git --version
```

**2. 查看工作区状态**

```bash
git status
```

**3. 在指定仓库查看近期历史**

```bash
git -C project log -5 --oneline
```

## 边界与易混淆点

具体操作按子命令分别检索；Git 不等于 GitHub，提交到本地不会自动推送到远程。
