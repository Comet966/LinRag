# crontab 检索说明

## 用途与查询表达

管理用户的周期性定时任务。适用实现：cronie / Vixie cron。

- 添加定时任务。
- 查看定时任务。
- 编辑 crontab。
- 时间格式怎么写。

## 参数与行为

- `-e`：编辑当前用户的任务。
- `-l`：列出当前用户的任务。
- `-r`：删除整个 crontab。
- `-u USER`：指定用户，需 root。
- `-T`：只检查语法，不安装。

## 常见任务示例

**1. 查看任务（分时日月周）**

```bash
crontab -l
```

**2. 编辑任务（cron PATH 较简）**

```bash
crontab -e
```

## 边界与易混淆点

`-e` 编辑，`-l` 查看；字段为分时日月周，cron 环境变量和 PATH 较简，命令用绝对路径。
