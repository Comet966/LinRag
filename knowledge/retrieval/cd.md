# cd 检索说明

## 用途与查询表达

切换当前 shell 的工作目录。适用实现：Bash builtin。

- 进入文件夹。
- 回上一级目录。
- 返回刚才的目录。
- 回家目录。

## 参数与行为

- `-L`：按逻辑路径处理符号链接和 ..。
- `-P`：按物理目录结构处理符号链接和 ..。
- `-`：回到上一次工作目录。
- `..`：切换到上级目录。

## 常见任务示例

**1. 进入日志目录**

```bash
cd /var/log
```

**2. 返回上一次所在目录**

```bash
cd -
```

## 边界与易混淆点

cd 是 shell 内建命令；不带目录时进入 HOME。单独的 - 是目录操作数，.. 是路径，不是选项。
