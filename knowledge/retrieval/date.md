# date 检索说明

## 用途与查询表达

显示或设置系统日期和时间。适用实现：GNU coreutils。

- 格式化日期。
- 打印时间戳。
- 显示 UTC。
- 查看某日期。

## 参数与行为

- `-u`：按 UTC 显示或设置时间。
- `-d STRING`：解析指定日期字符串并显示，不设置系统时间。
- `-r FILE`：显示文件最后修改时间。
- `-I`：按 ISO 日期格式输出。

## 常见任务示例

**1. 按指定格式显示当前本地时间**

```bash
date '+%Y-%m-%d %H:%M:%S'
```

**2. 查看当前 UTC 时间**

```bash
date -u '+%Y-%m-%dT%H:%M:%SZ'
```

**3. 将 Unix 秒级时间戳转换为 UTC 日期**

```bash
date -u -d '@1700000000'
```

## 边界与易混淆点

-d 只解析和显示；+FORMAT 控制输出格式，%s 表示 Unix 时间戳秒数。本文示例不修改系统时钟。
