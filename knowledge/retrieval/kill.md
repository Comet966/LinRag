# kill 检索说明

## 用途与查询表达

向进程发送信号，默认请求正常终止。适用实现：Bash / Linux kill common subset。

- 结束进程。
- 发送信号。
- 停止卡住程序。
- TERM 与 KILL 区别。

## 参数与行为

- `-s SIGNAL`：按名称指定信号，如 TERM。
- `-l`：列出信号名称。
- `-TERM`：发送可被进程处理的终止信号。
- `-KILL`：强制结束，进程不能捕获或忽略。

## 常见任务示例

**1. 向 PID 1234 请求正常终止**

```bash
kill -s TERM 1234
```

**2. 列出可发送的信号，便于选择**

```bash
kill -l
```

## 边界与易混淆点

1234 是示例 PID，使用前需核实。默认 TERM；KILL 无法让进程自行清理。这里只覆盖 Bash 和常见 Linux 实现共有用法。
