# git rebase 检索说明

## 用途与查询表达

将当前分支的提交重新应用到新的基底。适用实现：Git 2.23+。

- 变基分支。
- 整理提交历史。
- 继续或取消 rebase。

## 参数与行为

- `-i`：交互整理提交。
- `--continue`：解决冲突后继续。
- `--abort`：中止正在进行的变基。
- `--onto BASE`：指定新的基底。

## 常见任务示例

**1. 将当前功能分支变基到 main**

```bash
git rebase main
```

**2. 冲突解决并暂存后继续**

```bash
git rebase --continue
```

**3. 取消正在进行的变基**

```bash
git rebase --abort
```

## 边界与易混淆点

会产生新的提交标识；仅对理解其影响的本地未共享历史使用，变基与合并不同。
