# tcpdump 检索说明

## 用途与查询表达

抓取并分析网络接口上的数据包。适用实现：tcpdump。

- 抓指定网卡的包。
- 抓包看网页请求。
- 没权限怎么办。
- 抓包存文件分析。

## 参数与行为

- `-i`：指定网卡，`any` 表示全部
- `-c`：抓够指定包数后自动停止
- `-n`：不把地址和端口解析成名字
- `-w`：把原始数据包写入文件
- `-r`：从保存的文件里读取数据包
- `-A`：以 ASCII 形式显示报文内容

## 常见任务示例

**1. 抓 10 个包后自动停止**

```bash
sudo tcpdump -i any -c 10 -n
```

**2. 看 5 个 80 端口报文**

```bash
sudo tcpdump -i any -c 5 -n port 80 -A
```

**3. 存包供离线分析**

```bash
sudo tcpdump -i eth0 -c 100 -w cap.pcap
```

## 边界与易混淆点

需 root；报文含敏感明文，`-w` 生成的文件要限权保管，不加 `-c` 会一直抓。
