# fsck 检索说明

## 用途与查询表达

检查并修复文件系统错误。适用实现：util-linux。

- 检查文件系统错误。
- 开机提示文件系统损坏。
- 修复 ext4 分区。
- fsck 会做什么。

## 参数与行为

- `-A`：按 fstab 检查所有文件系统。
- `-N`：只显示将执行的操作。
- `-n`：只检查不修复。
- `-y`：自动修复，可能丢数据。
- `-r`：输出检查统计，不是交互。

## 常见任务示例

**1. 只检查不修复（先卸载）**

```bash
sudo fsck -n /dev/sdX1
```

**2. 演练会执行哪些检查**

```bash
sudo fsck -N -A
```

## 边界与易混淆点

`fsck` 是前端，ext 系列调用 `e2fsck`；不要修复已挂载的读写文件系统。`-r` 是统计，不是交互。
