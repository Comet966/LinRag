# head 检索说明

## 用途与查询表达

显示文件开头的部分内容。适用实现：GNU coreutils。

- 查看文件开头。
- 预览前几行。
- 查看表头。

## 参数与行为

- `-n N`：输出前 N 行，默认 10 行。
- `-c N`：输出前 N 字节。
- `-q`：多个输入文件也不显示文件名标题。
- `-v`：始终显示文件名标题。

## 常见任务示例

**1. 查看日志的前二十行**

```bash
head -n 20 app.log
```

**2. 预览文件开头的 100 字节**

```bash
head -c 100 sample.txt
```

## 边界与易混淆点

head 取开头，tail 取结尾；-c 以字节计数，可能截断多字节字符。
