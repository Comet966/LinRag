# echo 检索说明

## 用途与查询表达

输出字符串或变量。适用实现：Bash 内建 / GNU coreutils。

- 输出变量值。
- echo 不换行。
- 输出彩色文字。
- echo 有何不同。

## 参数与行为

- `-n`：结尾不加换行。
- `-e`：解释 \n、\t 等转义。
- `-E`：关闭转义解释。
- `\c`：终止输出，不再换行。
- `"$变量"`：双引号内展开变量。
- `--help`：仅外部 echo 识别。

## 常见任务示例

**1. 输出变量值**

```bash
echo "HOME=$HOME"
```

**2. 不换行输出提示**

```bash
echo -n 'loading'
```

**3. 解释换行转义**

```bash
echo -e '第一行\n第二行'
```

## 边界与易混淆点

内建 echo 不解析 --help，转义行为随 shell 变；任意数据用 printf。
