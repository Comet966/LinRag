# mv 检索说明

## 用途与查询表达

移动文件或目录，也可用于重命名。适用实现：GNU coreutils。

- 改文件名。
- 移动文件夹。
- 把文件移到另一个目录。

## 参数与行为

- `-i`：覆盖已有目标前询问。
- `-v`：显示移动过程。
- `-T`：将目标作为普通路径处理，不作为容器目录。
- `-t DIR`：指定目标目录。

## 常见任务示例

**1. 重命名文件，覆盖前询问**

```bash
mv -i old.txt new.txt
```

**2. 把文件移入归档目录，覆盖前询问**

```bash
mv -i report.txt archive/
```

## 边界与易混淆点

目标是已有目录时，通常移入该目录；跨文件系统移动通常需要复制再删除源文件。
