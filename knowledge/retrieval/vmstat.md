# vmstat 检索说明

## 用途与查询表达

报告进程、内存、IO 与 CPU 状态。适用实现：procps-ng。

- 系统卡顿看哪里。
- 内存还剩多少。
- CPU 空闲率怎么看。
- 换页是否频繁。

## 参数与行为

- `-s`：以表格给出内存与事件计数。
- `-d`：显示磁盘统计。
- `-p`：只显示指定分区的统计。
- `-w`：宽输出，字段更易读。
- `-S`：指定单位，m 表示 MiB。
- `-n`：表头只打印一次。

## 常见任务示例

**1. 每秒一次共五次**

```bash
vmstat 1 5
```

**2. 看内存与事件总计**

```bash
vmstat -s
```

**3. 看磁盘读写统计**

```bash
vmstat -d
```

## 边界与易混淆点

第一行是开机以来的平均值，看趋势从第二行起；free 小但 si/so 为 0 时内存并不紧张。
