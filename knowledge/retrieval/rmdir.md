# rmdir 检索说明

## 用途与查询表达

删除空目录。适用实现：GNU coreutils。

- 移除空文件夹。
- 清理空目录。
- 删除空的多级路径。

## 参数与行为

- `-p`：依次尝试删除指定目录及其空父目录。
- `-v`：显示删除的目录。
- `--ignore-fail-on-non-empty`：忽略目录非空导致的失败。

## 常见任务示例

**1. 删除一个空文件夹**

```bash
rmdir empty-dir
```

**2. 删除空目录，并继续删除空的父目录**

```bash
rmdir -p work/cache/empty
```

## 边界与易混淆点

只能删除空目录；非空目录不能用 rmdir 删除。-p 可能继续删除空父目录。
