# seq 检索说明

## 用途与查询表达

按指定增量从首数打印到尾数。适用实现：GNU coreutils。

- 生成数字序列。
- 循环用数字列表。
- 生成补零序号。
- 拼接数字成一行。

## 参数与行为

- `-w`：输出等宽，前面补零。
- `-s 分隔符`：改用指定分隔符连接。
- `-f 格式`：按 printf 浮点格式输出。
- `尾数`：只给终点，从 1 开始。
- `首数 尾数`：省略增量，默认为 1。
- `首数 增量 尾数`：增量可为小数。

## 常见任务示例

**1. 从 1 打印到 5**

```bash
seq 5
```

**2. 生成等宽补零序号**

```bash
seq -w 8 11
```

**3. 一行空格分隔输出**

```bash
seq -s ' ' 1 5
```

## 边界与易混淆点

`-w` 不能和 `-f` 同用；小增量有浮点误差；`seq` 是外部命令，可移植脚本用循环替代。
