# git branch 检索说明

## 用途与查询表达

列出、创建或管理本地分支。适用实现：Git 2.23+。

- 查看所有分支。
- 创建分支。
- 查看上游分支。

## 参数与行为

- `-a`：显示本地和远程跟踪分支。
- `-vv`：显示跟踪关系和最近提交。
- `-m NAME`：重命名当前分支。
- `-d NAME`：删除满足合并条件的本地分支。

## 常见任务示例

**1. 列出全部已知分支**

```bash
git branch -a
```

**2. 检查分支跟踪关系**

```bash
git branch -vv
```

**3. 创建但不切换到新分支**

```bash
git branch feature/demo
```

## 边界与易混淆点

创建分支不会自动切换；-d 涉及删除，-D 会跳过合并检查，应避免误删未合并工作。
