# mkfs 检索说明

## 用途与查询表达

在设备上创建文件系统，会清空数据。适用实现：util-linux。

- 怎么格式化分区。
- 创建 ext4 分区。
- 怎么创建 xfs。
- 格式化前怎么演练。

## 参数与行为

- `-t TYPE`：指定文件系统类型。
- `-V`：显示将执行的命令。
- `-L LABEL`：设置卷标（ext 系列）。
- `-n`：只演练不写入（ext 系列）。
- `-F`：强制创建，慎用（ext 系列）。

## 常见任务示例

**1. 在占位分区创建 ext4**

```bash
sudo mkfs -t ext4 /dev/sdX1
```

**2. 只演练不写入（ext 系列）**

```bash
sudo mkfs.ext4 -n /dev/sdX1
```

## 边界与易混淆点

`mkfs` 只是前端，实际调用 `mkfs.ext4` 等；会清空目标数据，先确认设备。
