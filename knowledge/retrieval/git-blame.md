# git blame 检索说明

## 用途与查询表达

逐行显示文件内容最后修改的提交和作者。适用实现：Git 2.23+。

- 追踪哪次提交修改一行。
- 查看代码作者。
- 定位某段代码历史。

## 参数与行为

- `-L START,END`：限定行号范围。
- `-w`：忽略空白差异。
- `--show-email`：显示作者邮箱。

## 常见任务示例

**1. 查看文件逐行来源**

```bash
git blame README.md
```

**2. 只查看指定行范围**

```bash
git blame -L 10,30 -- README.md
```

**3. 忽略空白变化追溯内容**

```bash
git blame -w -- README.md
```

## 边界与易混淆点

显示最后一次相关修改，不代表代码最初作者；路径和行号需要在目标版本中存在。
