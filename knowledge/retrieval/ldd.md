# ldd 检索说明

## 用途与查询表达

列出程序或库依赖的共享库。适用实现：glibc。

- 缺哪个 so 库。
- 程序起不来。
- lib 依赖关系。
- 库版本不匹配。

## 参数与行为

- `-v`：显示全部依赖与版本信息。
- `-u`：只报告未使用的依赖。
- `-d`：报告缺失的数据重定位。
- `-r`：报告缺失的函数重定位。
- `--version`：显示版本号。

## 常见任务示例

**1. 查看可执行文件依赖的库**

```bash
ldd /bin/ls
```

**2. 详细看依赖版本信息**

```bash
ldd -v /bin/ls
```

**3. 不执行程序也能看依赖**

```bash
objdump -p /bin/ls | grep NEEDED
```

## 边界与易混淆点

`ldd` 会用动态加载器执行目标，别对不可信程序运行；改用 `objdump -p` 查 NEEDED。
