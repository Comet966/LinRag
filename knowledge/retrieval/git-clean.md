# git clean 检索说明

## 用途与查询表达

预览或删除工作区中的未跟踪文件。适用实现：Git 2.23+。

- 清理未跟踪文件。
- 预览删除构建产物。
- 清理 Git 忽略文件。

## 参数与行为

- `-n`：仅预览，不删除。
- `-d`：包括未跟踪目录。
- `-i`：交互选择清理内容。
- `-x`：也考虑被忽略的文件。

## 常见任务示例

**1. 预览未跟踪文件**

```bash
git clean -n
```

**2. 预览未跟踪目录和文件**

```bash
git clean -nd
```

**3. 仅预览指定构建目录**

```bash
git clean -nd -- build/
```

## 边界与易混淆点

此卡片仅提供只读预览；加入 -f、-x 等实际清理选项可能永久删除未跟踪文件，Git 通常无法找回。
