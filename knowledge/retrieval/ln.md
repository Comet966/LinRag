# ln 检索说明

## 用途与查询表达

为文件建立硬链接或符号链接。适用实现：GNU coreutils。

- 创建快捷路径。
- 建立软链接。
- 给文件创建硬链接。

## 参数与行为

- `-s`：建立符号链接，也称软链接。
- `-i`：替换目标前询问。
- `-f`：移除已有目标路径。
- `-v`：显示创建的链接。

## 常见任务示例

**1. 给日志文件建立软链接**

```bash
ln -s /var/log/app.log app.log
```

**2. 为同一文件系统中的文件建立硬链接**

```bash
ln report.txt report-hardlink.txt
```

## 边界与易混淆点

默认硬链接通常不能跨文件系统，也不能链接目录；相对软链接的目标按链接所在目录解析。
