# pgrep 检索说明

## 用途与查询表达

按名称或条件查找进程并输出 PID。适用实现：procps-ng。

- 查程序的 PID。
- 根据进程名定位。
- 找完整命令行。
- 避免 grep 自身匹配。

## 参数与行为

- `-f`：匹配完整命令行。
- `-x`：要求完整匹配进程名或命令行。
- `-a`：同时输出完整命令行。
- `-u USER`：按有效用户筛选。
- `-n`：只选最新启动的匹配进程。
- `-o`：只选最早启动的匹配进程。

## 常见任务示例

**1. 显示名称为 sshd 的进程及命令行**

```bash
pgrep -a -x sshd
```

**2. 按完整命令行查找 Python 服务**

```bash
pgrep -af 'python.*server.py'
```

## 边界与易混淆点

默认匹配进程名，通常有长度限制；长启动命令用 -f。pgrep 只查询，不发送终止信号。
