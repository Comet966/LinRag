# paste 检索说明

## 用途与查询表达

把多个文件按列并排或串行合并。适用实现：GNU coreutils。

- 两文件按行并排。
- 用逗号拼接各列。
- 一列拆成多行。
- 行列不对齐怎么办。

## 参数与行为

- `-d`：指定列间分隔符，默认制表符。
- `-s`：串行处理，每个文件占一行。
- `-z`：以 NUL 作为行分隔符。
- `--help`：显示帮助信息。
- `--version`：显示版本号。

## 常见任务示例

**1. 两文件按列合并**

```bash
paste a.txt b.txt
```

**2. 用逗号分隔各列**

```bash
paste -d, a.txt b.txt
```

**3. 每个文件合并成一行**

```bash
paste -s a.txt b.txt
```

## 边界与易混淆点

按行号硬对齐，行数不齐时补空列；行内容不匹配，需要关联字段请用 `join`。
