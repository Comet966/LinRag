# wait 检索说明

## 用途与查询表达

等待后台作业或进程结束。适用实现：Bash 内建。

- 脚本等后台跑完。
- 怎么等全部子进程。
- 作业号怎么写。
- 和 jobs 配合用。

## 参数与行为

- `%1`：按作业号等待。
- `PID`：按进程号等待。
- `-n`：等任意一个作业结束。
- `-f`：等作业真正终止。
- `$!`：最后一个后台进程的 PID。

## 常见任务示例

**1. 等所有后台任务结束**

```bash
sleep 5 & sleep 3 & wait
```

**2. 按作业号等待**

```bash
sleep 5 & wait %1
```

**3. 等最近的后台进程**

```bash
sleep 5 & wait $!
```

## 边界与易混淆点

是内建，只能等本 shell 的子进程；作业号要带 `%`，裸数字按 PID；不带参数等全部。
