# lsmod 检索说明

## 用途与查询表达

列出已加载的内核模块，读 /proc/modules。适用实现：kmod。

- 看已加载模块。
- 模块加载成功没。
- 模块占用多少内存。
- 谁依赖这个模块。

## 参数与行为

- 无选项：输出直接来自 `/proc/modules`。
- 第一列是模块名，第二列是大小。
- 第三列是用量，即被引用次数。
- 第四列列出依赖它的模块。
- 看模块详情要用 `modinfo`。
- 卸载模块用 `modprobe -r`。

## 常见任务示例

**1. 查看全部已加载模块**

```bash
lsmod
```

**2. 过滤确认某模块是否加载**

```bash
lsmod | grep -i ext4
```

## 边界与易混淆点

`lsmod` 只读 `/proc/modules`，不加载也不卸载；加载用 `modprobe`，卸载用 `modprobe -r`。
