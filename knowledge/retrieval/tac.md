# tac 检索说明

## 用途与查询表达

按行倒序输出文件内容。适用实现：GNU coreutils。

- 从后往前看日志。
- 倒序打印文件。
- 和 -b 的差别。
- 自定义分隔符。

## 参数与行为

- `-s`：用指定分隔符代替换行符
- `-r`：把分隔符当作基本正则
- `-b`：把分隔符附在前一条记录前
- `--help`：显示帮助信息
- `--version`：显示版本信息

## 常见任务示例

**1. 倒序打印文件内容**

```bash
tac /etc/hosts
```

**2. 取最后几行再倒着看**

```bash
tail -n 5 /var/log/syslog | tac
```

**3. 用冒号作分隔符倒序**

```bash
printf 'a:b:c' | tac -s ':'
```

## 边界与易混淆点

多个文件各自倒序、不合并；`-b` 把分隔符附在记录前，末尾可能不带换行。
