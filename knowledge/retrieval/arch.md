# arch 检索说明

## 用途与查询表达

显示当前主机的硬件架构名称。适用实现：GNU coreutils。

- 查看机器架构。
- arch 输出什么。
- 等价于哪个命令。
- 判断 CPU 架构。

## 参数与行为

- `--help`：显示帮助并退出。
- `--version`：显示版本并退出。
- `arch`：不带参数直接输出架构名。
- `uname -m`：等价写法，输出相同。
- 其余开关：`arch` 不接受其他选项。

## 常见任务示例

**1. 查看本机硬件架构**

```bash
arch
```

**2. 与 uname -m 对照确认**

```bash
arch && uname -m
```

## 边界与易混淆点

只输出架构名，等价 `uname -m`；更完整信息用 `uname -a` 或 `lscpu`。
