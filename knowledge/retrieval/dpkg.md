# dpkg 检索说明

## 用途与查询表达

操作本地 deb 包和包数据库。适用实现：dpkg。

- 安装本地 deb 包。
- 依赖报错修复。
- 查文件所属包。
- 查看 deb 内容。

## 参数与行为

- `-i 包.deb`：安装本地 deb 包。
- `-r 包名`：卸载，保留配置。
- `-P 包名`：卸载并删除配置。
- `-L 包名`：列出包安装的文件。
- `-S 路径`：反查文件所属包。
- `-l`：列出已安装的包。

## 常见任务示例

**1. 安装本地 deb 包**

```bash
sudo dpkg -i ./app_1.0_amd64.deb
```

**2. 补齐缺失的依赖**

```bash
sudo apt-get install -f
```

**3. 查文件属于哪个包**

```bash
dpkg -S /usr/sbin/nginx
```

## 边界与易混淆点

dpkg 不联网也不解决依赖，缺依赖用 apt-get -f install；-r 保留配置，-P 才删除。
