# sync 检索说明

## 用途与查询表达

把内存缓冲区数据强制写入磁盘。适用实现：GNU coreutils。

- 数据还没落盘。
- 拔 U 盘前刷盘。
- sync 有何作用。
- 缓存何时写盘。

## 参数与行为

- `-d`：只同步文件数据，跳过元数据
- `-f`：只同步指定文件所在的文件系统
- `<文件>`：只同步与这些文件相关的数据
- `--help`：显示帮助信息
- `--version`：显示版本信息

## 常见任务示例

**1. 手动刷新全部缓冲数据**

```bash
sync
```

**2. 只同步某个文件系统**

```bash
sync -f /home
```

**3. 只写回数据不写元数据**

```bash
sync -d /home/user/a.txt
```

## 边界与易混淆点

`sync` 只是发起写回，安全拔盘仍要 `umount`；`-d` 不同步元数据，可能丢文件大小等信息。
