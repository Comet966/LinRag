# last 检索说明

## 用途与查询表达

查看用户登录和系统重启历史。适用实现：util-linux。

- 查看登录历史。
- 谁最近登录过。
- 查看重启记录。
- 查看某个用户记录。

## 参数与行为

- `-n N`：只显示最近 N 条。
- `-x`：显示重启和关机记录。
- `-f FILE`：指定记录文件。
- `-i`：显示来源 IP。
- `-F`：显示完整时间。

## 常见任务示例

**1. 查看最近登录记录**

```bash
last
```

**2. 只看最近 10 条**

```bash
last -n 10
```

## 边界与易混淆点

`last` 读 wtmp，`who` 只看当前会话；`lastb` 看失败登录。
