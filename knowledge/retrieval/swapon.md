# swapon 检索说明

## 用途与查询表达

启用交换区并查看其使用情况。适用实现：util-linux。

- 查看 swap 用量。
- 加交换文件。
- 设置交换优先级。
- swapon 的用法。

## 参数与行为

- `-s`：概要显示已启用的交换区
- `--show`：按列显示交换区，可选 NAME
- `-p`：设定优先级，数值越大越先用
- `-a`：启用 fstab 里所有 swap 项
- `-h`：显示帮助信息
- `-V`：显示版本信息

## 常见任务示例

**1. 查看交换区名称与用量**

```bash
swapon --show
```

**2. 概要显示交换区和优先级**

```bash
swapon -s
```

**3. 只列出名称和优先级两列**

```bash
swapon --show=NAME,PRIO
```

## 边界与易混淆点

启用交换区要 root；示例只用 `-s`、`--show` 等只读形式，不改动交换区状态。
