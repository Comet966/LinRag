# pip check 检索说明

## 用途与查询表达

检查已安装包的依赖是否缺失或版本不兼容。适用实现：pip（示例通过 Python 3 调用）。

- 检查 Python 依赖冲突。
- 检查缺失的包依赖。
- 验证虚拟环境依赖。

## 参数与行为

- `--help`：显示帮助。
- `--verbose`：增加诊断输出，属于 pip 的全局选项。

## 常见任务示例

**1. 检查当前环境依赖**

```bash
python3 -m pip check
```

**2. 显示更详细的诊断**

```bash
python3 -m pip --verbose check
```

## 边界与易混淆点

返回非零表示检测到问题；不会自动安装或修复依赖，也不能替代应用测试。
