# ps 检索说明

## 用途与查询表达

显示进程的当前快照。适用实现：procps-ng。

- 查看进程列表。
- 查看 PID。
- 查看父进程。
- 查看启动命令。

## 参数与行为

- `-e`：显示所有进程。
- `-f`：使用完整格式。
- `-p PID`：筛选指定进程。
- `-u USER`：按有效用户筛选。
- `-o FORMAT`：指定输出字段。

## 常见任务示例

**1. 列出所有进程的完整信息**

```bash
ps -ef
```

**2. 查看指定进程的 PID、父进程和启动命令**

```bash
ps -p 1234 -o pid,ppid,args
```

**3. 查看指定用户的进程**

```bash
ps -u alice -f
```

## 边界与易混淆点

这是一次性快照，持续刷新用 top。常见 ps aux 是 BSD 选项组合，不应写成含糊的 ps -aux。
