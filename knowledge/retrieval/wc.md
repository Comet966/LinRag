# wc 检索说明

## 用途与查询表达

统计文件的行数、单词数、字节数等。适用实现：GNU coreutils。

- 统计文本行数。
- 文件多少字节。
- 字符数和字节数区别。

## 参数与行为

- `-l`：统计换行符数量。
- `-w`：统计单词数。
- `-c`：统计字节数。
- `-m`：按当前区域设置统计字符数。
- `-L`：显示最长行的显示宽度。

## 常见任务示例

**1. 统计日志中的换行符数量**

```bash
wc -l access.log
```

**2. 统计文本的字符数和字节数**

```bash
wc -m -c notes.txt
```

## 边界与易混淆点

没有末尾换行的最后一行不增加 -l 计数；多字节文本中 -c 和 -m 结果可能不同。
