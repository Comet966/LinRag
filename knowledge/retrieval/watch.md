# watch 检索说明

## 用途与查询表达

周期性执行命令并全屏刷新输出。适用实现：procps-ng。

- 每隔两秒刷新输出。
- 实时看内存变化。
- watch 改刷新间隔。
- 输出变化时退出。

## 参数与行为

- `-n 秒`：设置刷新间隔，默认 2 秒。
- `-d`：高亮本次刷新中的变化。
- `-t`：隐藏顶部标题栏。
- `-g`：输出变化时退出。
- `-x`：不经 shell 执行命令。
- `-p`：按精确间隔刷新。

## 常见任务示例

**1. 每秒刷新内存**

```bash
watch -n 1 -d 'free -h'
```

**2. 每两秒看日志末尾**

```bash
watch -n 2 'tail -n 5 app.log'
```

**3. 隐藏标题栏看负载**

```bash
watch -n 5 -t 'uptime'
```

## 边界与易混淆点

watch 默认 2 秒刷新，-n 改间隔；它只刷新显示，不是定时任务。
