# mtr 检索说明

## 用途与查询表达

探测各跳延迟与丢包，诊断链路。适用实现：mtr。

- 哪一跳开始丢包。
- 到目标网络质量。
- 路由和延迟。
- 和 ping 区别。

## 参数与行为

- `-r`：报告模式，打印后退出。
- `-c N`：发 N 次探测后结束。
- `-n`：不解析主机名，只显示 IP。
- `-s SIZE`：设置探测包大小。
- `-w`：宽格式报告，不截断名称。
- `-T`：改用 TCP 方式探测。
- `-b`：主机名与 IP 一起显示。

## 常见任务示例

**1. 生成固定次数的报告**

```bash
mtr -r -c 10 example.com
```

**2. 报告模式且不解析域名**

```bash
mtr -r -n -c 10 example.com
```

**3. 宽格式看完整主机名**

```bash
mtr -rw -c 10 example.com
```

## 边界与易混淆点

中间跳丢包不一定影响终点，要看终点那一跳；`-r` 出报告，`-w` 才不截断主机名。
