# mkdir 检索说明

## 用途与查询表达

创建目录。适用实现：GNU coreutils。

- 创建文件夹。
- 建立嵌套目录。
- 新建目录并设置权限。

## 参数与行为

- `-p`：同时创建缺失的父目录，已存在的目录不报错。
- `-m MODE`：设置新建目标目录的权限，如 755。

## 常见任务示例

**1. 一次创建多级目录**

```bash
mkdir -p project/src
```

**2. 创建仅属主可访问的目录**

```bash
mkdir -m 700 private
```

## 边界与易混淆点

-m 不决定 -p 自动创建的父目录权限；父目录权限受 umask 等影响。
