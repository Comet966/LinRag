# id 检索说明

## 用途与查询表达

显示用户 ID、组 ID 以及所属组。适用实现：GNU coreutils。

- 当前用户 UID。
- 用户属于哪些组。
- 检查用户身份。
- 真实与有效用户。

## 参数与行为

- `-u`：只显示有效用户 ID。
- `-g`：只显示有效组 ID。
- `-G`：显示所有组 ID。
- `-n`：配合 -u、-g 或 -G 输出名称。
- `-r`：配合 -u、-g 或 -G 查询真实身份。

## 常见任务示例

**1. 查看当前用户所属的组名**

```bash
id -nG
```

**2. 查询指定用户的 UID**

```bash
id -u alice
```

## 边界与易混淆点

不指定用户时查询当前进程身份；只看有效用户名可用 whoami。
