# at 检索说明

## 用途与查询表达

在指定时间执行一次性任务。适用实现：at。

- 定时执行一次命令。
- 十分钟后跑脚本。
- 查看待执行任务。
- atd 没启动怎么办。

## 参数与行为

- `-f FILE`：从文件读取要执行的命令。
- `-m`：任务结束后给用户发邮件。
- `-q Q`：指定队列，常用 a 或 b。
- `-l`：列出待执行任务，等同 `atq`。
- `-d`：删除任务，等同 `atrm`。
- `-c`：打印任务脚本内容。

## 常见任务示例

**1. 明天 17:20 运行脚本**

```bash
at -f /tmp/task.sh 17:20 tomorrow
```

**2. 十分钟后运行一次**

```bash
at -f /tmp/task.sh now + 10 minutes
```

**3. 打印任务内容核对**

```bash
at -c 1
```

## 边界与易混淆点

按提交者身份执行，需 `atd` 在运行；`-l` 等同 `atq`，`-d` 等同 `atrm`。
