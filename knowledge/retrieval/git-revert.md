# git revert 检索说明

## 用途与查询表达

通过新增反向提交撤销已有提交的改动。适用实现：Git 2.23+。

- 撤销已推送提交。
- 生成反向提交。
- revert 与 reset 区别。

## 参数与行为

- `--no-commit`：应用反向改动但暂不提交。
- `--continue`：解决冲突后继续。
- `--abort`：中止撤销过程。

## 常见任务示例

**1. 撤销最近一次提交并编辑说明**

```bash
git revert HEAD
```

**2. 先生成反向改动再检查**

```bash
git revert --no-commit HEAD
```

**3. 冲突后取消撤销过程**

```bash
git revert --abort
```

## 边界与易混淆点

保留已有历史，适用于共享提交；仍会修改工作区且可能冲突，撤销合并提交还需要明确主线。
