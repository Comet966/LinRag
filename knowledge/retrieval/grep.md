# grep 检索说明

## 用途与查询表达

搜索文本中匹配模式的行。适用实现：GNU grep。

- 查找文件内容。
- 搜索错误日志。
- 递归找关键字。
- 显示匹配上下文。

## 参数与行为

- `-i`：忽略大小写。
- `-n`：显示行号。
- `-r`：递归搜索目录。
- `-E`：使用扩展正则表达式。
- `-F`：把模式作为固定字符串。
- `-v`：只显示不匹配的行。
- `-l`：只显示包含匹配的文件名。
- `-c`：统计匹配行数。
- `-A N`：显示匹配行之后 N 行。
- `-B N`：显示匹配行之前 N 行。
- `-C N`：显示匹配行前后各 N 行。

## 常见任务示例

**1. 定位日志中包含 ERROR 的行**

```bash
grep -n 'ERROR' app.log
```

**2. 递归搜索配置目录中的固定字符串**

```bash
grep -rnF 'server_name' config/
```

**3. 同时查找两类错误，并显示前后两行**

```bash
grep -nE -C 2 'ERROR|FATAL' app.log
```

**4. 统计包含错误标记的行数**

```bash
grep -c 'ERROR' app.log
```

## 边界与易混淆点

-c 统计匹配行而不是出现次数；grep 搜索正文，find 搜索路径和文件属性。大写 -F 表示固定字符串。
