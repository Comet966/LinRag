# tree 检索说明

## 用途与查询表达

以树状图递归列出目录内容。适用实现：tree。

- 树状查看目录结构。
- 目录太多怎么看。
- 限制显示层级。
- 忽略某些目录。

## 参数与行为

- `-L`：限制显示的最大目录层级。
- `-d`：只显示目录，不显示文件。
- `-a`：显示包括隐藏项在内的全部条目。
- `-I`：按模式忽略匹配的条目。
- `-P`：只显示匹配模式的条目。
- `-f`：显示每个条目的完整相对路径。

## 常见任务示例

**1. 只看两层目录**

```bash
tree -L 2 /tmp/demo
```

**2. 忽略指定目录**

```bash
tree -I 'node_modules|.git' -L 2 /tmp/demo
```

**3. 目录树存入文件**

```bash
tree -L 2 /tmp/demo > /tmp/demo.tree
```

## 边界与易混淆点

非 POSIX 标准命令，部分系统需自行安装；只看单层可用 `-L 1`，只列目录加 `-d`。
