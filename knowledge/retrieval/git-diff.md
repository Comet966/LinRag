# git diff 检索说明

## 用途与查询表达

比较工作区、暂存区或指定提交之间的差异。适用实现：Git 2.23+。

- 查看代码差异。
- 比较暂存区。
- 比较两个分支改动。

## 参数与行为

- `--staged`：比较暂存区与 HEAD。
- `--stat`：显示文件变更统计。
- `--name-only`：只列出变化路径。
- `--check`：检查新增的空白格式问题。

## 常见任务示例

**1. 查看尚未暂存的修改**

```bash
git diff
```

**2. 查看准备提交的差异**

```bash
git diff --staged
```

**3. 比较两个分支**

```bash
git diff --stat main..feature/demo
```

## 边界与易混淆点

默认不显示未跟踪文件；双点比较两个端点，三点从共同祖先比较到第二个端点。
