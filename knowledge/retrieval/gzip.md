# gzip 检索说明

## 用途与查询表达

压缩或解压单个文件，默认替换原文件。适用实现：gzip。

- 压缩日志文件。
- 解压 gz 文件。
- 保留原文件压缩。
- 查看 gz 内容。

## 参数与行为

- `-d`：解压，等价于 gunzip。
- `-k`：保留原文件。
- `-c`：结果写到标准输出。
- `-l`：列出压缩包信息。
- `-t`：测试压缩文件完整性。
- `-r`：递归处理目录中的文件。

## 常见任务示例

**1. 压缩并保留原文件**

```bash
gzip -k app.log
```

**2. 解压并删除 .gz**

```bash
gzip -d app.log.gz
```

**3. 查看压缩包内容**

```bash
gzip -dc app.log.gz | less
```

## 边界与易混淆点

默认原地替换并删除原文件，加 -k 才保留；gzip 不打包目录，多个文件先用 tar。
