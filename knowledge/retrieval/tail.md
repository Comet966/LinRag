# tail 检索说明

## 用途与查询表达

显示文件末尾内容，也可持续跟踪新增内容。适用实现：GNU coreutils。

- 实时追踪日志。
- 查看最后几行。
- 日志切割后继续监控。

## 参数与行为

- `-n N`：输出末尾 N 行，默认 10 行。
- `-c N`：输出末尾 N 字节。
- `-f`：持续跟踪，默认跟随文件描述符。
- `-F`：按文件名跟踪并重试，适合日志轮转。
- `--pid=PID`：跟踪时在指定进程结束后退出。
- `-s N`：设置部分跟踪场景的检查间隔秒数。

## 常见任务示例

**1. 持续查看日志，包括文件轮转后新增的内容**

```bash
tail -F app.log
```

**2. 只查看最后 50 行，不持续跟踪**

```bash
tail -n 50 app.log
```

**3. 查看新追加内容，按描述符持续跟踪**

```bash
tail -f app.log
```

## 边界与易混淆点

-f 默认跟随已打开的文件，改名后可能继续读旧文件；-F 相当于 --follow=name --retry。
