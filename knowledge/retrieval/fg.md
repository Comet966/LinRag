# fg 检索说明

## 用途与查询表达

Bash 内建，把作业切换到前台运行。适用实现：Bash 内建。

- 作业切回前台。
- fg 恢复挂起作业。
- 后台任务转前台。
- 作业号怎么用。

## 参数与行为

- `%1`：按作业号切换到前台。
- `%+`/`%%`：指当前作业。
- `%-`：指上一个作业。
- `%?str`：按命令行子串匹配作业。
- `fg`：省略作业号即为当前作业。
- `help fg`：查看内建帮助。

## 常见任务示例

**1. 把作业 1 切回前台**

```bash
fg %1
```

**2. 恢复最近挂起的作业**

```bash
fg
```

**3. 按命令名匹配后切回**

```bash
fg %?sleep
```

## 边界与易混淆点

仅在交互式 shell 且开启作业控制时可用，`fg` 只切换运行状态，不会重建进程。
