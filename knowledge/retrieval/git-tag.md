# git tag 检索说明

## 用途与查询表达

列出或创建提交的标签。适用实现：Git 2.23+。

- 创建版本标签。
- 查看发布版本。
- Git 附注标签。

## 参数与行为

- `-l PATTERN`：按模式列出标签。
- `-a NAME`：创建附注标签。
- `-m MESSAGE`：指定附注内容。
- `--points-at REV`：列出指向某提交的标签。

## 常见任务示例

**1. 列出版本标签**

```bash
git tag -l 'v*'
```

**2. 为当前提交创建附注标签**

```bash
git tag -a v1.0.0 -m 'Release 1.0.0'
```

**3. 查看指向 HEAD 的标签**

```bash
git tag --points-at HEAD
```

## 边界与易混淆点

标签默认只保存在本地，需要明确 push 才发送到远程；不要复用已发布的版本标签。
