# parted 检索说明

## 用途与查询表达

查看磁盘分区表并做分区管理。适用实现：parted。

- 查看磁盘分区表。
- 磁盘容量对不上。
- 大于 2T 的盘分区。
- 不交互直接打印。

## 参数与行为

- `-l`：列出所有磁盘的分区表。
- `-s`：脚本模式，不提示交互。
- `-m`：以机器可读格式输出。
- `-a opt`：设置分区对齐方式。
- `-v`：显示版本号。
- `print`：只读打印分区表信息。

## 常见任务示例

**1. 列出所有磁盘分区表**

```bash
parted -l
```

**2. 只读查看指定磁盘**

```bash
parted /dev/sdb print
```

**3. 查看磁盘空闲空间**

```bash
parted /dev/sdb print free
```

## 边界与易混淆点

`print` 和 `-l` 只读；`mkpart`、`rm` 会立即写盘，动手前先备份分区表。
