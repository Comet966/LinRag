# atrm 检索说明

## 用途与查询表达

删除排队中的 at 任务。适用实现：at。

- 删除待执行任务。
- 取消 at 任务。
- 任务号怎么查。
- 删掉排错的任务。

## 参数与行为

- `JOB`：要删除的作业号，可写多个。
- `-V`：只显示版本号。
- `at -d JOB`：与 `atrm` 等价的写法。
- `atq`：先查出作业号再删除。
- `sudo atrm`：删他人任务需 root。

## 常见任务示例

**1. 删除作业号为 1 的任务**

```bash
atrm 1
```

**2. 先列队核对再删除**

```bash
atq
atrm 2
```

## 边界与易混淆点

删除后无法恢复；普通用户只能删自己的任务，root 可删全部。
