# zip 检索说明

## 用途与查询表达

创建或更新 ZIP 压缩包。适用实现：Info-ZIP Zip。

- 创建 zip 压缩包。
- 打包目录给其他系统。
- 排除文件压缩。

## 参数与行为

- `-r`：递归包含子目录。
- `-q`：减少输出。
- `-9`：使用最高压缩级别。
- `-u`：更新较新的文件并添加新文件。
- `-x PATTERN`：排除匹配的路径。

## 常见任务示例

**1. 把项目目录压缩为 ZIP**

```bash
zip -r project.zip project/
```

**2. 压缩目录，同时排除日志文件**

```bash
zip -r project.zip project/ -x '*.log'
```

## 边界与易混淆点

修改已有 ZIP 时是更新归档，源目录中被删除的项不一定从归档删除；解压使用 unzip。
