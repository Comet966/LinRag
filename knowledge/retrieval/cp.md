# cp 检索说明

## 用途与查询表达

复制文件或目录。适用实现：GNU coreutils。

- 拷贝文件。
- 复制整个文件夹。
- 保留权限备份目录。

## 参数与行为

- `-r`：递归复制目录。
- `-a`：归档复制，递归并尽量保留属性和链接。
- `-i`：覆盖已有文件前询问。
- `-v`：显示复制过程。
- `-p`：保留模式、属主和时间戳等属性。

## 常见任务示例

**1. 复制项目目录并尽量保留属性**

```bash
cp -a project project-backup
```

**2. 复制单个文件，覆盖前询问**

```bash
cp -i report.txt backup/
```

**3. 递归复制目录，并显示复制的路径**

```bash
cp -rv assets/ staging/
```

## 边界与易混淆点

目标目录若已存在，会把源放入其中；保留属主等属性可能需要权限。cp 不会自动同步删除目标多余文件。
