# arp 检索说明

## 用途与查询表达

查看和修改 IPv4 的 ARP 缓存。适用实现：net-tools。

- 查看 ARP 缓存。
- IP 对应哪个 MAC。
- 绑一条静态 ARP。
- 清掉错误缓存条目。

## 参数与行为

- `-n`：以数字形式显示 IP 地址。
- `-a`：按 BSD 风格列出全部条目。
- `-v`：显示条目和统计信息。
- `-i IFACE`：只操作指定网卡。
- `-d HOST`：删除该主机的缓存条目。
- `-s HOST MAC`：加静态映射，需 root。
- `-e`：用 Linux 默认显示风格。

## 常见任务示例

**1. 数字形式查看缓存表**

```bash
arp -n
```

**2. 只看 eth0 上的条目**

```bash
arp -n -i eth0
```

**3. 查看全部条目和统计**

```bash
arp -av
```

## 边界与易混淆点

只管 IPv4 邻居缓存，改表需 root；IPv6 邻居用 `ip -6 neigh` 看。
