# du 检索说明

## 用途与查询表达

估算文件和目录占用的磁盘空间。适用实现：GNU coreutils。

- 哪个文件夹占空间。
- 统计目录大小。
- 排查大目录。
- 文件逻辑大小。

## 参数与行为

- `-h`：以易读单位显示。
- `-s`：只显示每个参数的合计。
- `-a`：同时列出普通文件。
- `--max-depth=N`：限制显示的目录层级。
- `--apparent-size`：显示逻辑大小而非磁盘块占用。

## 常见任务示例

**1. 查看项目目录占用的总空间**

```bash
du -sh project/
```

**2. 查看当前目录下一层子目录的磁盘占用**

```bash
du -h --max-depth=1 .
```

## 边界与易混淆点

默认按磁盘块占用计量，稀疏文件的逻辑大小可能更大；统计整个分区可用空间用 df。
