# atq 检索说明

## 用途与查询表达

列出待执行的 at 任务队列。适用实现：at。

- 查看我的 at 任务。
- 任务队列在哪看。
- 只看 a 队列。
- 没有任务输出为空。

## 参数与行为

- `-q Q`：只看指定队列的任务。
- `-v`：显示已执行未清理的任务。
- `-V`：只显示版本号。
- `atq`：不带参数列出本用户任务。
- `sudo atq`：以 root 查看所有用户。

## 常见任务示例

**1. 查看本用户的待执行任务**

```bash
atq
```

**2. 只看 a 队列的任务**

```bash
atq -q a
```

**3. 以 root 查看所有用户任务**

```bash
sudo atq
```

## 边界与易混淆点

无输出表示没有待执行任务；普通用户只看到自己的，root 可见全部。
