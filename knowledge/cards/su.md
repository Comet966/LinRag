## su

切换到其他用户身份。

### 常用参数

- `su -`：登录式切换，加载完整环境。
- `su`：非登录式，保留当前环境。
- `-c 'CMD'`：以目标用户执行一条命令。
- `-s SHELL`：指定使用的 shell。
- `-m`：保留当前环境变量。
- `-g GROUP`：指定主组，仅 root 可用。

### 常用例子

**1. 切换到 root 登录环境**

```bash
su -
```

**2. 以 alice 执行命令**

```bash
su - alice -c 'id'
```

**3. 保留当前环境切换**

```bash
su -m alice
```
