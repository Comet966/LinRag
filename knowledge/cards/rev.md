## rev

把每行内容按字符反序输出。

### 常用参数

- `文件...`：要反序输出的文件，可多个。
- `不给文件参数`：默认从标准输入读取。
- `-0, --zero`：用 NUL 作行分隔符。
- `--`：之后的内容都当作文件名。
- `-h, --help`：显示帮助后退出。
- `-V, --version`：显示版本信息。

### 常用例子

**1. 反序查看一行文本**

```bash
echo 'hello world' | rev
```

**2. 逐行反序显示文件内容**

```bash
rev /etc/hosts
```

**3. 反序后接管道继续处理**

```bash
rev access.log | head -n 5
```
