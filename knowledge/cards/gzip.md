## gzip

压缩或解压单个文件，默认替换原文件。

### 常用参数

- `-d`：解压，等价于 gunzip。
- `-k`：保留原文件。
- `-c`：结果写到标准输出。
- `-l`：列出压缩包信息。
- `-t`：测试压缩文件完整性。
- `-r`：递归处理目录中的文件。

### 常用例子

**1. 压缩并保留原文件**

```bash
gzip -k app.log
```

**2. 解压并删除 .gz**

```bash
gzip -d app.log.gz
```

**3. 查看压缩包内容**

```bash
gzip -dc app.log.gz | less
```
