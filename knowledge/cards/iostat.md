## iostat

查看磁盘 I/O 与 CPU 的使用情况。

### 常用参数

- `-x`：显示扩展的 I/O 统计。
- `-d`：只显示设备统计。
- `-c`：只显示 CPU 统计。
- `-k`：以 kB/s 为单位显示。
- `-m`：以 MB/s 为单位显示。
- `-y`：跳过开机以来的首份报告。
- `-z`：不显示没有活动的设备。

### 常用例子

**1. 每秒采样一次共三次**

```bash
iostat 1 3
```

**2. 只看扩展磁盘指标**

```bash
iostat -x 1 3
```

**3. 省略首份并按 kB 输出**

```bash
iostat -dxky 1 3
```
