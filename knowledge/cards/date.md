## date

显示或设置系统日期和时间。

### 常用参数

- `-u`：按 UTC 显示或设置时间。
- `-d STRING`：解析指定日期字符串并显示，不设置系统时间。
- `-r FILE`：显示文件最后修改时间。
- `-I`：按 ISO 日期格式输出。

### 常用例子

**1. 按指定格式显示当前本地时间**

```bash
date '+%Y-%m-%d %H:%M:%S'
```

**2. 查看当前 UTC 时间**

```bash
date -u '+%Y-%m-%dT%H:%M:%SZ'
```

**3. 将 Unix 秒级时间戳转换为 UTC 日期**

```bash
date -u -d '@1700000000'
```
