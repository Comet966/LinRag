## ss

查看套接字连接和监听端口。

### 常用参数

- `-l`：只显示监听套接字。
- `-a`：显示监听和非监听套接字。
- `-n`：使用数字地址和端口，不解析名称。
- `-t`：筛选 TCP。
- `-u`：筛选 UDP。
- `-p`：显示关联进程。
- `-s`：显示摘要。

### 常用例子

**1. 查看 TCP 监听端口及关联进程**

```bash
ss -lntp
```

**2. 查看当前 TCP 连接，使用数字地址和端口**

```bash
ss -tn
```

**3. 查看 UDP 监听套接字及关联进程**

```bash
ss -lunp
```
