## host

查询域名的 DNS 记录与反向解析。

### 常用参数

- `-t A`：只查指定类型的记录。
- `-a`：显示全部 DNS 信息。
- `-v`：显示查询的详细过程。
- `-4`/`-6`：只用 IPv4 或 IPv6。
- `-W 2`：设置等待应答的秒数。
- `-r`：关闭递归查询。

### 常用例子

**1. 查域名对应的 IP**

```bash
host example.com
```

**2. 只查 MX 邮件记录**

```bash
host -t MX example.com
```

**3. 反查 IP 对应的域名**

```bash
host 8.8.8.8
```
