## objdump

查看目标文件和可执行文件结构。

### 常用参数

- `-h`：列出各节的头部摘要。
- `-d`：反汇编可执行代码节。
- `-t`：显示符号表入口。
- `-r`：显示重定位入口。
- `-s`：显示指定节的完整内容。
- `-C`：把符号名还原成 C++ 名。
- `-S`：反汇编并穿插源码，隐含 `-d`。

### 常用例子

**1. 看二进制里有哪些节**

```bash
objdump -h /bin/ls
```

**2. 反汇编并还原 C++ 符号**

```bash
objdump -d -C /bin/ls
```

**3. 只看符号表**

```bash
objdump -t /bin/ls
```
