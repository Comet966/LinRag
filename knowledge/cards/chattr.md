## chattr

修改 ext 系文件系统的属性位。

### 常用参数

- `+i`：不可变：禁改、禁删、禁改名。
- `+a`：只允许追加，不能删改。
- `-i`：取消不可变属性。
- `-R`：递归处理目录及其内容。
- `-V`：显示详细执行过程。
- `-v VER`：设置文件版本号。
- `-f`：忽略大部分错误信息。

### 常用例子

**1. 锁定关键文件防止被改**

```bash
chattr +i /etc/fstab
```

**2. 日志只允许追加内容**

```bash
chattr +a /var/log/app.log
```

**3. 递归取消不可变属性**

```bash
chattr -R -i /data/app
```
