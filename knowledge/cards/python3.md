## python3

运行 Python 3 程序、模块或交互解释器。

### 常用参数

- `-V`：显示解释器版本。
- `-m MODULE`：按模块名运行。
- `-c CODE`：运行给定代码。
- `-u`：使用无缓冲的标准输出和错误。

### 常用例子

**1. 查看 Python 版本**

```bash
python3 -V
```

**2. 在新目录创建虚拟环境**

```bash
python3 -m venv .venv-demo
```

**3. 格式化并检查 JSON**

```bash
python3 -m json.tool data.json
```
