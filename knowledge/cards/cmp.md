## cmp

逐字节比较，报首个差异位置。

### 常用参数

- `-l`：列出所有不同字节的偏移。
- `-s`：不输出内容，只看退出码。
- `-b`：同时显示差异处的字符。
- `-c`：打印差异处的字符编码。
- `-i N`：跳过开头 N 个字节再比。
- `-n N`：最多只比较前 N 个字节。

### 常用例子

**1. 比较两个文件是否相同**

```bash
cmp a.txt b.txt
```

**2. 列出全部差异字节**

```bash
cmp -l a.txt b.txt
```

**3. 脚本里只用退出码判断**

```bash
cmp -s a.txt b.txt
```
