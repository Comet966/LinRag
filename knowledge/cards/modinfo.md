## modinfo

查看内核模块的描述与参数。

### 常用参数

- `-n`：只显示模块文件路径。
- `-a`：只显示作者。
- `-d`：只显示描述。
- `-l`：只显示许可证。
- `-p`：只显示模块参数。
- `-F FIELD`：只显示指定字段。
- `-0`：字段之间用 NUL 分隔。

### 常用例子

**1. 查看模块的全部信息**

```bash
modinfo ext4
```

**2. 只看模块文件路径**

```bash
modinfo -n ext4
```

**3. 只列出模块参数**

```bash
modinfo -p ext4
```
