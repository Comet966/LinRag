## 7z

高压缩比归档工具，支持多种格式。

### 常用参数

- `a`：添加文件，创建或更新压缩包。
- `x`：解压并保留原有目录结构。
- `e`：解压但忽略目录结构。
- `l`：只列出压缩包内容。
- `-o{DIR}`：指定输出目录，后不加空格。
- `-p{PASS}`：指定压缩包密码。
- `-mx=N`：压缩级别 0 到 9，9 最慢最小。

### 常用例子

**1. 列出压缩包内的文件**

```bash
7z l data.7z
```

**2. 解压到指定目录**

```bash
7z x data.7z -o/tmp/out
```

**3. 最高压缩级别打包目录**

```bash
7z a -mx=9 data.7z /tmp/out
```
