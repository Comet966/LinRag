## telnet

远程登录主机或探测端口连通性。

### 常用参数

- `-8`：允许传输 8 位字符
- `-l`：指定登录的远端用户名
- `-e`：设置转义字符，默认 `^]`
- `-E`：禁用转义字符
- `-K`：不自动登录远端主机
- `-d`：打开调试模式

### 常用例子

**1. 测试目标端口是否可达**

```bash
telnet 192.0.2.10 80
```

**2. 用指定用户登录远端**

```bash
telnet -l admin 192.0.2.10
```

**3. 允许 8 位字符登录**

```bash
telnet -8 192.0.2.10
```
