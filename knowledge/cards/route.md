## route

查看和设置内核静态路由表。

### 常用参数

- `-n`：不解析主机名，显示数字。
- `-e`：显示扩展信息，如 MTU。
- `-ee`：再叠加一层，输出更多列。
- `-A inet`：指定地址族，如 inet6。
- `-v`：详细模式输出。
- `-F`：操作内核 FIB 表，默认。

### 常用例子

**1. 数字形式查看路由表**

```bash
route -n
```

**2. 只看默认路由那一行**

```bash
route -n | grep '^0.0.0.0'
```

**3. 显示接口与 MTU 字段**

```bash
route -n -ee
```
