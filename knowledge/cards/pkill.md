## pkill

按进程名或匹配模式查找并发送信号。

### 常用参数

- `-0`：只检查是否存在，不发信号。
- `-f`：匹配完整命令行而非进程名。
- `-x`：要求进程名完全一致。
- `-n`：只对最新的匹配进程操作。
- `-o`：只对最早的匹配进程操作。
- `-u`：只匹配指定用户的进程。
- `-e`：显示被处理的进程号。

### 常用例子

**1. 只检查是否在运行**

```bash
pkill -0 -x sshd
```

**2. 按完整命令行匹配**

```bash
pkill -0 -f 'python3 /opt/app/worker.py'
```

**3. 限定用户再匹配**

```bash
pkill -0 -u deploy -f 'python3 worker.py'
```
