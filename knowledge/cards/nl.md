## nl

给文本加上行号后输出。

### 常用参数

- `-b a`：所有行都加行号。
- `-b t`：仅非空行加行号，默认。
- `-n rz`：行号右对齐并补前导零。
- `-w 宽度`：设行号字段宽度。
- `-s 分隔符`：设行号后的分隔串。
- `-v 起始值`：设每部分的起始行号。
- `-p`：换页时不重置行号。

### 常用例子

**1. 默认只给非空行编号**

```bash
nl notes.txt
```

**2. 空行也一起编号**

```bash
nl -ba notes.txt
```

**3. 行号定宽右对齐补零**

```bash
nl -n rz -w 4 notes.txt
```
