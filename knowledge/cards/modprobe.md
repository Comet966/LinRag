## modprobe

按依赖关系加载或卸载内核模块。

### 常用参数

- `-r`：卸载模块并清理依赖。
- `-D`：只显示依赖，不加载。
- `-n`：干跑，不真正加载。
- `-v`：显示执行过程。
- `-c`：显示最终生效的配置。
- `-q`：出错时不打印提示。

### 常用例子

**1. 干跑看加载顺序与依赖**

```bash
modprobe -n -v vfat
```

**2. 只看依赖关系不加载**

```bash
modprobe -D loop
```

**3. 干跑卸载模块及其依赖**

```bash
modprobe -n -r vfat
```
