## sysctl

查看与临时修改内核运行参数。

### 常用参数

- `-a`：显示全部可读的内核参数
- `-n`：只打印值，不打印键名
- `-N`：只打印参数名称
- `-e`：忽略未知键名的错误
- `-p`：从配置文件加载参数设置
- `-w`：写入参数值，会修改内核

### 常用例子

**1. 查看全部内核参数**

```bash
sysctl -a
```

**2. 只读取一个参数的值**

```bash
sysctl -n vm.swappiness
```

**3. 按前缀筛出 TCP 参数**

```bash
sysctl -a | grep net.ipv4.tcp
```
