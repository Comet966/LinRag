## lsof

列出进程打开的文件，包括网络套接字。

### 常用参数

- `-p PID`：筛选指定进程。
- `-i SPEC`：筛选网络地址、协议或端口。
- `-n`：不将地址解析为主机名。
- `-P`：不将端口解析为服务名。
- `-a`：将不同筛选条件按逻辑与组合。
- `+L1`：选择链接计数小于 1 的已打开文件。

### 常用例子

**1. 查看使用 TCP 8080 端口的本机进程**

```bash
lsof -nP -i TCP:8080
```

**2. 查看指定进程打开的文件**

```bash
lsof -p 1234
```

**3. 查找已删除但仍被进程打开的文件**

```bash
lsof +L1
```

**4. 按进程和 TCP 连接两个条件同时筛选**

```bash
lsof -a -p 1234 -i TCP
```
