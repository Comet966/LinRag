## reboot

重启系统，需 root 权限。

### 常用参数

- `-f`：不再停服务，立即强制重启。
- `-w`：只写 wtmp 记录，不真重启。
- `-d`：不写 wtmp 登录记录。
- `--no-wall`：重启前不向用户发广播。
- `--no-sync`：重启前不刷写磁盘缓存。
- `--help`：显示帮助后退出。

### 常用例子

**1. 仅写记录，不真正重启**

```bash
reboot -w
```

**2. 演练重启且不广播**

```bash
reboot -w --no-wall
```

**3. 查看全部可用选项**

```bash
reboot --help
```
