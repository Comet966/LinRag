## batch

系统空闲时执行一次性任务。

### 常用参数

- `-f FILE`：从文件读取要执行的命令。
- `-m`：结束后给用户发邮件。
- `-q Q`：指定队列，默认 b 队列。
- `-v`：显示任务预计执行时间。
- `TIME`：可选的最早执行时间。
- `-V`：只显示版本号。

### 常用例子

**1. 系统空闲时运行脚本**

```bash
batch -f /tmp/report.sh
```

**2. 一小时后才允许执行**

```bash
batch -f /tmp/report.sh now + 1 hour
```

**3. 查看 b 队列排队情况**

```bash
atq -q b
```
