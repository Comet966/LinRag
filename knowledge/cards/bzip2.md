## bzip2

压缩成 bz2 格式的归档文件。

### 常用参数

- `-z`：强制压缩，缺省行为。
- `-d`：解压 bz2 文件。
- `-k`：压缩时保留原文件。
- `-f`：覆盖已存在的输出文件。
- `-t`：只检验完整性，不解压。
- `-c`：结果写到标准输出。
- `-9`：最高压缩级别，最慢。

### 常用例子

**1. 压缩并保留原文件**

```bash
bzip2 -k app.log
```

**2. 校验压缩包是否完好**

```bash
bzip2 -tv app.log.bz2
```

**3. 解压到标准输出查看**

```bash
bzip2 -dc app.log.bz2
```
