## parted

磁盘分区与调整分区大小的工具。

### 常用参数

- `-l`：列出所有磁盘的分区表。
- `-s`：脚本模式，不提示交互。
- `-m`：以机器可读格式输出。
- `-a opt`：设置分区对齐方式。
- `-v`：显示版本号。
- `print`：只读打印分区表信息。

### 常用例子

**1. 列出所有磁盘分区表**

```bash
parted -l
```

**2. 只读查看指定磁盘**

```bash
parted /dev/sdb print
```

**3. 查看磁盘空闲空间**

```bash
parted /dev/sdb print free
```
