## rg

快速递归搜索文件内容，默认遵循忽略规则。

### 常用参数

- `-n`：显示行号。
- `-i`：忽略大小写。
- `-F`：按固定字符串匹配。
- `-g GLOB`：按路径模式筛选文件。
- `--hidden`：包括隐藏路径。
- `--files`：列出候选文件。

### 常用例子

**1. 搜索代码目录中的字符串**

```bash
rg -n 'TODO' src/
```

**2. 只搜索 Python 文件**

```bash
rg -n -g '*.py' 'def main' .
```

**3. 按固定字符串搜索**

```bash
rg -F '127.0.0.1' config/
```
