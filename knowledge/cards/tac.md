## tac

按行倒序输出文件内容。

### 常用参数

- `-s`：用指定分隔符代替换行符
- `-r`：把分隔符当作基本正则
- `-b`：把分隔符附在前一条记录前
- `--help`：显示帮助信息
- `--version`：显示版本信息

### 常用例子

**1. 倒序打印文件内容**

```bash
tac /etc/hosts
```

**2. 取最后几行再倒着看**

```bash
tail -n 5 /var/log/syslog | tac
```

**3. 用冒号作分隔符倒序**

```bash
printf 'a:b:c' | tac -s ':'
```
