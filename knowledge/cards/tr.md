## tr

按字符集转换、压缩或删除输入字符。

### 常用参数

- `-d`：删除字符集1中的字符。
- `-s`：把连续重复字符压缩成一个。
- `-c`：改用字符集1的补集来处理。
- `-t`：先把字符集1截断到与2等长。
- `[:upper:]`：字符类，表示大写字母。

### 常用例子

**1. 大写转小写**

```bash
echo 'HELLO WORLD' | tr 'A-Z' 'a-z'
```

**2. 删掉所有数字**

```bash
echo 'a1b2c3' | tr -d '0-9'
```

**3. 压缩连续空格**

```bash
echo 'a    b' | tr -s ' '
```
