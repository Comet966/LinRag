## lsattr

查看文件的 ext 文件系统属性标志。

### 常用参数

- `-R`：递归列出子目录中的文件。
- `-a`：包含以点开头的隐藏文件。
- `-d`：显示目录自身，不展开内容。
- `-l`：用长名称打印属性标志。
- `-p`：同时显示文件所属项目号。
- `-v`：显示文件的版本号。

### 常用例子

**1. 查看单个文件的属性标志**

```bash
lsattr /data/report.txt
```

**2. 用长名称看属性的含义**

```bash
lsattr -l /data/report.txt
```

**3. 递归查看目录内所有文件**

```bash
lsattr -R /data/project
```
