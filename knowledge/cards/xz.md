## xz

高压缩率压缩单个文件，默认替换原文件。

### 常用参数

- `-d`：解压，等价于 unxz。
- `-k`：保留输入文件。
- `-l`：查看压缩包信息。
- `-T 数量`：线程数，`-T0` 用全部核心。
- `-0 到 -9`：压缩预设，默认 6。
- `-e`：extreme 模式提高压缩率。

### 常用例子

**1. 压缩并保留原文件**

```bash
xz -k backup.tar
```

**2. 解压并保留压缩包**

```bash
xz -dk backup.tar.xz
```

**3. 查看压缩信息**

```bash
xz -l backup.tar.xz
```
