## locate

从索引数据库快速查找文件路径。

### 常用参数

- `-i`：匹配时忽略大小写。
- `-c`：只输出匹配数量。
- `-l N`：限制输出的条目数。
- `-b`：只匹配路径最后一段。
- `-e`：只输出仍然存在的结果。
- `-S`：打印数据库的统计信息。

### 常用例子

**1. 查找名称含 sshd 的路径**

```bash
locate sshd
```

**2. 忽略大小写并限制条数**

```bash
locate -i -l 5 nginx
```

**3. 只统计仍存在的匹配数**

```bash
locate -e -c nginx
```
