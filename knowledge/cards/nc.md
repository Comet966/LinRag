## nc

TCP/UDP 连接、监听与端口探测。

### 常用参数

- `-z`：只扫描端口，不发送数据。
- `-v`：显示连接过程与端口状态。
- `-l`：监听模式，等待对方连接。
- `-u`：改用 UDP 传输。
- `-w N`：连接或响应超时秒数。
- `-n`：不做域名解析。

### 常用例子

**1. 探测单个端口是否开放**

```bash
nc -zv -w 2 example.com 80
```

**2. 扫描一段端口范围**

```bash
nc -zv -w 2 192.0.2.10 1-1024
```

**3. 监听端口接收占位数据**

```bash
nc -l -p 8888 > /tmp/nc-recv.bin
```
