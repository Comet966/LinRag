## pidstat

按进程监控 CPU、内存与磁盘 IO。

### 常用参数

- `-u`：显示 CPU 使用统计，默认项。
- `-r`：显示内存使用统计。
- `-d`：显示磁盘 IO 统计。
- `-w`：显示上下文切换统计。
- `-p`：只统计指定进程号。
- `-t`：细化到线程级统计。
- `-l`：显示完整命令行参数。

### 常用例子

**1. 每 2 秒采样 CPU，共 3 次**

```bash
pidstat -u 2 3
```

**2. 只看指定进程的内存**

```bash
pidstat -r -p 1234 1 3
```

**3. 查看线程级 CPU 占用**

```bash
pidstat -t -u 1 2
```
