## nethogs

按进程实时查看网络带宽占用。

### 常用参数

- `-d 秒`：设刷新间隔，默认 1 秒。
- `-v 模式`：切换单位，0 为 KB/s。
- `-c 次数`：刷新够次数后自动退出。
- `-t`：跟踪模式，输出不刷屏。
- `-s`：按发送流量排序。
- `-a`：连环回等接口一起监控。

### 常用例子

**1. 每 2 秒刷新一次总览**

```bash
sudo nethogs -d 2
```

**2. 只看 eth0 的进程流量**

```bash
sudo nethogs -d 1 eth0
```

**3. 记 10 次后自动退出**

```bash
sudo nethogs -t -c 10
```
