## ethtool

查看和设置网卡链路与卸载参数。

### 常用参数

- `-i`：显示驱动名、版本和固件。
- `-S`：显示网卡和驱动的统计计数。
- `-k`：查看校验、分段等卸载状态。
- `-K`：开关卸载功能，如 rx off。
- `-s`：设置速度、双工和自协商。
- `-p`：让网口指示灯闪烁定位。
- `-a`：查看收发暂停帧的状态。

### 常用例子

**1. 查看链路速度和双工**

```bash
ethtool eth0
```

**2. 查看驱动与固件版本**

```bash
ethtool -i eth0
```

**3. 让网口灯闪 10 秒定位**

```bash
ethtool -p eth0 10
```
