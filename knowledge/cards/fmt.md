## fmt

把文本段落重排到指定列宽。

### 常用参数

- `-w 72`：设定每行最大列宽。
- `-s`：只拆长行，不合并短行。
- `-u`：词间单空格，句末双空格。
- `-c`：保留段首两行的缩进。
- `-t`：按段首缩进区分标记段。
- `-p STR`：只合并以 STR 开头的行。

### 常用例子

**1. 按 72 列重排文本**

```bash
fmt -w 72 note.txt
```

**2. 只拆分长行不合并**

```bash
fmt -s -w 60 note.txt
```

**3. 统一空格与句距**

```bash
fmt -u -w 72 note.txt
```
