## sort

对文本行排序。

### 常用参数

- `-n`：按数值排序。
- `-r`：逆序排序。
- `-k KEY`：按指定字段或字段范围排序。
- `-t CHAR`：指定字段分隔符。
- `-u`：去除排序键相同的重复项。
- `-h`：按带 K、M、G 等单位的数值排序。

### 常用例子

**1. 按数字大小排列各行**

```bash
sort -n numbers.txt
```

**2. 按冒号分隔的第三列数值排序**

```bash
sort -t ':' -k 3,3n /etc/passwd
```

**3. 对名称列表排序并去重**

```bash
sort -u names.txt
```
