## nmap

探测主机开放端口和服务版本。

### 常用参数

- `-sT`：TCP 连接扫描，无需 root。
- `-sV`：探测端口上的服务版本。
- `-p`：指定端口，如 22,80 或 1-100。
- `-sn`：只发现主机，不扫端口。
- `-Pn`：跳过存活检测直接扫。
- `-O`：尝试识别目标操作系统。
- `-oN 文件`：结果按普通文本存盘。

### 常用例子

**1. 扫授权主机的常用端口**

```bash
nmap -Pn -p 22,80,443 192.0.2.10
```

**2. 探测授权主机的服务版本**

```bash
nmap -sV 192.0.2.10
```

**3. 先确认网段里有谁在线**

```bash
nmap -sn 192.0.2.0/24
```
