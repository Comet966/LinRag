## ltrace

跟踪进程对库函数的调用。

### 常用参数

- `-c`：统计各调用次数与耗时。
- `-f`：同时跟踪子进程。
- `-e FILTER`：只跟踪匹配的函数。
- `-p PID`：附加到运行中的进程。
- `-S`：同时显示系统调用。
- `-T`：显示每次调用的耗时。
- `-o FILE`：把输出写入文件。

### 常用例子

**1. 统计程序的库调用与耗时**

```bash
ltrace -c /bin/ls
```

**2. 跟踪子进程并写入日志**

```bash
ltrace -f -o /tmp/ltrace.log /bin/ls
```

**3. 附加到占位 PID 的进程**

```bash
ltrace -p 1234
```
