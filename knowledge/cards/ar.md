## ar

创建、查看或展开静态库归档。

### 常用参数

- `r`：替换或新增成员文件。
- `t`：列出归档中的成员名。
- `x`：把成员解出到当前目录。
- `d`：从归档中删除成员。
- `s`：生成或更新符号索引。
- `v`：配合 `t`、`r` 输出详情。
- `U`：改用真实时间戳和属主。

### 常用例子

**1. 把目标文件打包成静态库**

```bash
ar rcs libutil.a add.o sub.o
```

**2. 列出库中的成员文件**

```bash
ar t libutil.a
```

**3. 详细查看成员大小和时间**

```bash
ar tv libutil.a
```
