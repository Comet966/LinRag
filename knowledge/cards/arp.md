## arp

查看和修改内核的 ARP 缓存表。

### 常用参数

- `-n`：以数字形式显示 IP 地址。
- `-a`：按 BSD 风格列出全部条目。
- `-v`：显示条目和统计信息。
- `-i IFACE`：只操作指定网卡。
- `-d HOST`：删除该主机的缓存条目。
- `-s HOST MAC`：加静态映射，需 root。
- `-e`：用 Linux 默认显示风格。

### 常用例子

**1. 数字形式查看缓存表**

```bash
arp -n
```

**2. 只看 eth0 上的条目**

```bash
arp -n -i eth0
```

**3. 查看全部条目和统计**

```bash
arp -av
```
