## tree

以树状图列出目录及其子目录内容。

### 常用参数

- `-L`：限制显示的最大目录层级。
- `-d`：只显示目录，不显示文件。
- `-a`：显示包括隐藏项在内的全部条目。
- `-I`：按模式忽略匹配的条目。
- `-P`：只显示匹配模式的条目。
- `-f`：显示每个条目的完整相对路径。

### 常用例子

**1. 只看两层目录**

```bash
tree -L 2 /tmp/demo
```

**2. 忽略指定目录**

```bash
tree -I 'node_modules|.git' -L 2 /tmp/demo
```

**3. 目录树存入文件**

```bash
tree -L 2 /tmp/demo > /tmp/demo.tree
```
