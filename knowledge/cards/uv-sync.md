## uv sync

将项目环境同步为锁文件和依赖组要求的状态。

### 常用参数

- `--locked`：锁文件需保持最新，否则报错。
- `--frozen`：使用现有锁文件而不检查新鲜度。
- `--no-dev`：排除默认的 dev 依赖组。
- `--inexact`：保留未被项目要求的额外包。

### 常用例子

**1. 同步当前项目环境**

```bash
uv sync
```

**2. 要求锁文件已是最新再同步**

```bash
uv sync --locked
```

**3. 不安装默认开发依赖组**

```bash
uv sync --no-dev
```
