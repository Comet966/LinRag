## watch

周期性执行命令并刷新输出。

### 常用参数

- `-n 秒`：设置刷新间隔，默认 2 秒。
- `-d`：高亮本次刷新中的变化。
- `-t`：隐藏顶部标题栏。
- `-g`：输出变化时退出。
- `-x`：不经 shell 执行命令。
- `-p`：按精确间隔刷新。

### 常用例子

**1. 每秒刷新内存**

```bash
watch -n 1 -d 'free -h'
```

**2. 每两秒看日志末尾**

```bash
watch -n 2 'tail -n 5 app.log'
```

**3. 隐藏标题栏看负载**

```bash
watch -n 5 -t 'uptime'
```
