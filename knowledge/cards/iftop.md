## iftop

实时查看网卡各连接的流量。

### 常用参数

- `-i IFACE`：指定监听的网卡。
- `-n`：不把 IP 反解成主机名。
- `-N`：不把端口解析成服务名。
- `-B`：以字节而不是比特显示。
- `-P`：在主机后显示端口号。
- `-F NET`：只统计指定网段流量。
- `-t`：文本模式输出，便于记录。

### 常用例子

**1. 监控默认网卡并直显 IP**

```bash
iftop -n
```

**2. 指定网卡并显示端口**

```bash
iftop -i eth0 -n -P
```

**3. 按字节看某个网段流量**

```bash
iftop -i eth0 -n -B -F 192.168.1.0/24
```
