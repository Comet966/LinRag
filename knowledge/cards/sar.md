## sar

采样并报告系统资源使用统计。

### 常用参数

- `-u`：CPU 利用率统计。
- `-r`：内存使用率统计。
- `-b`：磁盘 I/O 速率。
- `-d`：块设备活动统计。
- `-n DEV`：网卡流量统计。
- `-P ALL`：每个 CPU 分别统计。
- `-f 文件`：读历史 sa 数据文件。

### 常用例子

**1. 每秒采样 CPU 共三次**

```bash
sar -u 1 3
```

**2. 查看内存使用情况**

```bash
sar -r 1 3
```

**3. 读取历史采样文件**

```bash
sar -u -f /var/log/sa/sa20
```
