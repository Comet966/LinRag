## printf

按格式串格式化输出。

### 常用参数

- `-v 变量`：结果存入变量不打印。
- `%s`：输出字符串。
- `%d`：输出整数。
- `%f`：输出浮点数。
- `%q`：转成可回填 shell 的引用。
- `%(FMT)T`：按格式输出时间。

### 常用例子

**1. 对齐打印表格**

```bash
printf '%-10s %6s\n' 'name' 'score'
```

**2. 保留两位小数**

```bash
printf '%.2f\n' 3.14159
```

**3. 输出当前时间**

```bash
printf '%(%Y-%m-%d %H:%M:%S)T\n' -1
```
