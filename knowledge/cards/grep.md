## grep

搜索文本中匹配模式的行。

### 常用参数

- `-i`：忽略大小写。
- `-n`：显示行号。
- `-r`：递归搜索目录。
- `-E`：使用扩展正则表达式。
- `-F`：把模式作为固定字符串。
- `-v`：只显示不匹配的行。
- `-l`：只显示包含匹配的文件名。
- `-c`：统计匹配行数。
- `-A N`：显示匹配行之后 N 行。
- `-B N`：显示匹配行之前 N 行。
- `-C N`：显示匹配行前后各 N 行。

### 常用例子

**1. 定位日志中包含 ERROR 的行**

```bash
grep -n 'ERROR' app.log
```

**2. 递归搜索配置目录中的固定字符串**

```bash
grep -rnF 'server_name' config/
```

**3. 同时查找两类错误，并显示前后两行**

```bash
grep -nE -C 2 'ERROR|FATAL' app.log
```

**4. 统计包含错误标记的行数**

```bash
grep -c 'ERROR' app.log
```
