## cp

复制文件或目录。

### 常用参数

- `-r`：递归复制目录。
- `-a`：归档复制，递归并尽量保留属性和链接。
- `-i`：覆盖已有文件前询问。
- `-v`：显示复制过程。
- `-p`：保留模式、属主和时间戳等属性。

### 常用例子

**1. 复制项目目录并尽量保留属性**

```bash
cp -a project project-backup
```

**2. 复制单个文件，覆盖前询问**

```bash
cp -i report.txt backup/
```

**3. 递归复制目录，并显示复制的路径**

```bash
cp -rv assets/ staging/
```
