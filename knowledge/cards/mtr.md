## mtr

边探测边统计各跳链路质量。

### 常用参数

- `-r`：报告模式，打印后退出。
- `-c N`：发 N 次探测后结束。
- `-n`：不解析主机名，只显示 IP。
- `-s SIZE`：设置探测包大小。
- `-w`：宽格式报告，不截断名称。
- `-T`：改用 TCP 方式探测。
- `-b`：主机名与 IP 一起显示。

### 常用例子

**1. 生成固定次数的报告**

```bash
mtr -r -c 10 example.com
```

**2. 报告模式且不解析域名**

```bash
mtr -r -n -c 10 example.com
```

**3. 宽格式看完整主机名**

```bash
mtr -rw -c 10 example.com
```
