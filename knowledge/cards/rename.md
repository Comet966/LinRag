## rename

按字面串批量替换文件名。

### 常用参数

- `-v`：打印每个改名结果。
- `-n`：只演示，不真正改名。
- `-a`：替换所有匹配，不只第一个。
- `-l`：只替换最后一次匹配。
- `-s`：作用在符号链接目标上。
- `-V`：显示版本，可分辨实现。

### 常用例子

**1. 把 txt 后缀批量改成 md**

```bash
rename -v .txt .md *.txt
```

**2. 先试运行看清改名结果**

```bash
rename -n foo foo0 foo?
```

**3. 把文件名前缀转成小写**

```bash
rename -v IMG img IMG_*.jpg
```
